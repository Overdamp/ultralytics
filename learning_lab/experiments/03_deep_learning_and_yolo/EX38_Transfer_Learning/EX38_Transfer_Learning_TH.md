# 🧠 EX38: การเรียนรู้แบบถ่ายโอน (Transfer Learning)

การเรียนรู้แบบถ่ายโอน (Transfer Learning) เป็นรูปแบบการเรียนรู้ของเครื่อง (Machine Learning) ที่นำโมเดลซึ่งได้รับการพัฒนาสำหรับงานต้นทาง (เช่น การจำแนกวัตถุทั่วไป) กลับมาใช้ใหม่เป็นจุดเริ่มต้นในการฝึกสอนโมเดลสำหรับงานที่สองซึ่งเป็นงานเป้าหมาย (เช่น การตรวจจับวาล์วอุตสาหกรรมเฉพาะด้าน)

---

## 1. หลักการสำคัญ: การนำคุณลักษณะกลับมาใช้ใหม่ (The Core Principle: Feature Reuse)
โครงข่ายประสาทเทียมเชิงลึกเรียนรู้การแทนค่าคุณลักษณะในรูปแบบลำดับชั้น (Hierarchical Feature Representations) จากภาพ:

```
[ ภาพอินพุต ] ---> [ ชั้นแรกๆ (Early Layers) ] ---------> [ ชั้นลึก (Deep Layers) ] ---------> [ ส่วนหัวเอาต์พุต (Output Head) ]
                   - ขอบและส่วนโค้ง                       - รูปทรงและพื้นผิวที่ซับซ้อน           - การทำนายคลาส
                   - ความสามารถในการถ่ายโอนสูง             - ความสามารถในการถ่ายโอนต่ำ          - ไม่มีความสามารถในการถ่ายโอนเลย
```

*   **ชั้นแรกๆ (Early Layers):** ทำการสกัดคุณลักษณะทั่วไปในระดับต่ำ (Low-level Features) เช่น เส้นตรงแนวตั้ง/แนวนอน ระดับการไล่เฉดสีของแสง หรือวงกลมง่ายๆ ซึ่งคุณลักษณะเหล่านี้จะเหมือนกันในการทำงานด้านภาพเกือบทั้งหมด
*   **ชั้นลึก (Deep Layers):** รวมกลุ่มคุณลักษณะระดับต่ำเข้าด้วยกันเป็นชิ้นส่วนรูปทรงที่ซับซ้อนขึ้น (เช่น ดวงตา ล้อ หรือด้ามจับของวาล์ว)
*   **ส่วนหัวเอาต์พุต (Output Head):** จับคู่รูปทรงเหล่านี้เข้ากับคลาสของงานเฉพาะเจาะจง (เช่น คลาส 80 คลาสในชุดข้อมูล COCO)

การเรียนรู้แบบถ่ายโอนจะเก็บบันทึกส่วนสกัดคุณลักษณะในชั้นแรกๆ และชั้นลึกเอาไว้ แล้วเปลี่ยนเฉพาะส่วนหัวเอาต์พุตที่จำเพาะกับงานใหม่เท่านั้น

---

## 2. การฝึกสอนจากศูนย์เทียบกับการเรียนรู้แบบถ่ายโอน (Training from Scratch vs. Transfer Learning)

### A. การฝึกสอนจากศูนย์ (กำหนดค่าเริ่มต้นด้วยไฟล์ `.yaml`):
```bash
yolo train model=yolo26n.yaml data=data.yaml epochs=100
```
*   **น้ำหนักเริ่มต้น (Initial Weights):** สุ่มทั้งหมด
*   **พฤติกรรม:** โมเดลต้องเสียเวลาใน 30–50 รอบแรก (Epochs) เพื่อเรียนรู้ว่าเส้นตรงและรูปทรงพื้นฐานเป็นอย่างไร ต้องใช้ชุดข้อมูลขนาดใหญ่มาก (ภาพหลายล้านภาพ) และใช้เวลาฝึกสอนนาน เพื่อหลีกเลี่ยงปัญหาการเรียนรู้เกิน (Overfitting)

### B. การเรียนรู้แบบถ่ายโอน (กำหนดค่าเริ่มต้นด้วยไฟล์ `.pt`):
```bash
yolo train model=yolo26n.pt data=data.yaml epochs=50
```
*   **น้ำหนักเริ่มต้น (Initial Weights):** ผ่านการฝึกสอนมาก่อนแล้ว (Pre-trained) ด้วยชุดข้อมูล COCO (ซึ่งประกอบด้วยภาพจำนวน 330,000 ภาพ)
*   **พฤติกรรม:** โมเดลรู้วิธีตรวจจับขอบ ส่วนโค้ง และพื้นผิวโลหะอยู่แล้ว จึงต้องการเพียงไม่กี่รอบการเรียนรู้เพื่อจัดระบบรูปทรงเหล่านี้ในการตรวจจับคลาสที่คุณกำหนดเองทั้ง 26 คลาส และสามารถลู่เข้าสู่จุดที่เหมาะสมที่สุด (Convergence) ได้อย่างรวดเร็ว

## 🔬 กรณีศึกษาทางคอมพิวเตอร์วิทัศน์: การตรวจจับวาล์ว PTT (PTT Valve Detection)
ชุดข้อมูลของคุณ [overall-ptt-object-detection.v11i.yolov11](file:///home/luke/ai_training/ultralytics/datasets/coco8/overall-ptt-object-detection.v11i.yolov11) มีขนาดค่อนข้างเล็ก

หากคุณฝึกสอนโมเดล YOLO จากศูนย์ด้วยไฟล์ `yolo26n.yaml` โมเดลมีแนวโน้มที่จะเกิดปัญหาการเรียนรู้เกิน (Overfit) ประсบปัญหาในการจัดวางกรอบล้อมรอบ (Bounding Boxes) และได้คะแนน mAP ต่ำ การโหลดน้ำหนักที่ผ่านการฝึกสอนมาก่อนแล้วจาก `yolo26n.pt` จะช่วยให้โมเดลใช้ประโยชน์จากความรู้เดิมเกี่ยวกับขอบวงกลม (ซึ่งคล้ายกับหน้าแปลน `flanges` หรือเกจวัดแบบเข็ม `analog-gauges` เป็นอย่างมาก) และแท่งตรง (ซึ่งคล้ายกับด้ามโยก `lever-handles`) ส่งผลให้การฝึกสอนมีความเสถียรและมีความแม่นยำสูง
