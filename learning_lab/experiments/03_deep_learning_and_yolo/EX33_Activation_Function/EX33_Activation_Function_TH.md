# 🧠 EX33: ฟังก์ชันกระตุ้นการทำงาน (Activation Functions)

ฟังก์ชันกระตุ้นการทำงาน (Activation Functions) คือการดำเนินการทางคณิตศาสตร์ที่นำไปใช้กับเอาต์พุตของนิวรอนในโครงข่ายประสาท ทำหน้าที่เพิ่มคุณสมบัติความไม่เชิงเส้น (Non-linearity) ให้กับโครงข่าย ช่วยให้สามารถเรียนรู้รูปแบบที่ซับซ้อนและไม่เชิงเส้นได้

---

## 1. ทำไมจึงต้องใช้ฟังก์ชันกระตุ้นการทำงาน (Why Activation Functions are Required)
หากไม่มีฟังก์ชันกระตุ้นการทำงานแบบไม่เชิงเส้น ชั้นเชิงเส้นหลายชั้น (เช่น ใน MLP หรือ CNN) จะยุบรวมกันทางคณิตศาสตร์กลายเป็นการดำเนินการเชิงเส้นเพียงชั้นเดียว:

$$\mathbf{W}^{[2]} \left( \mathbf{W}^{[1]} \mathbf{x} + \mathbf{b}^{[1]} \right) + \mathbf{b}^{[2]} = \mathbf{W}_{\text{effective}} \mathbf{x} + \mathbf{b}_{\text{effective}}$$

ไม่ว่าโครงข่ายจะมีกี่ร้อยชั้นก็ตาม หากปราศจากฟังก์ชันกระตุ้นการทำงาน โครงข่ายจะสามารถจำลองได้เพียงเส้นตรงธรรมดา (แก้ได้เฉพาะปัญหาเชิงเส้นเท่านั้น)

---

## 2. ฟังก์ชันกระตุ้นการทำงานที่พบบ่อย (Common Activation Functions)

### A. Sigmoid (ซิกมอยด์)
แปลงค่าอินพุตให้อยู่ในช่วงความน่าจะเป็นระหว่าง 0 ถึง 1:

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

*   **ข้อเสีย:** ประสบปัญหาการสูญหายของความชัน (Vanishing Gradients) เมื่อค่าอินพุตมีค่าสุดโต่ง ส่งผลให้กระบวนการแพร่กระจายย้อนกลับทำงานช้าลงหรือหยุดทำงาน

### B. Rectified Linear Unit (ReLU)
แปลงค่าที่เป็นลบให้เป็นศูนย์ โดยคงค่าที่เป็นบวกไว้ตามเดิม:

$$f(x) = \max(0, x)$$

*   **ข้อดี:** คำนวณได้รวดเร็วมาก ช่วยป้องกันปัญหาการสูญหายของความชัน
*   **ข้อเสีย:** ปัญหา "Dying ReLU" ซึ่งนิวรอนที่หยุดทำงาน ($x < 0$) จะส่งออกความชันเป็น 0 ตลอดไป

### C. Leaky ReLU
อนุญาตให้มีความชันเล็กน้อยที่ไม่ใช่ศูนย์เมื่ออินพุตเป็นลบ เพื่อป้องกันปัญหานิวรอนหยุดทำงาน:

$$f(x) = \max(0.01x, x)$$

### D. Sigmoid Linear Unit / Swish (SiLU - ค่าเริ่มต้นของ YOLO)
ฟังก์ชันกระตุ้นการทำงานแบบควบคุมตัวเองที่มีความราบเรียบ (Smooth, Self-gated):

$$f(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}$$

*   **ทำไม YOLO จึงใช้ SiLU:** เนื่องจากมีความโค้งที่เรียบและสามารถหาอนุพันธ์ได้อย่างต่อเนื่อง (ต่างจากมุมหักศอกของ ReLU ที่ $x=0$) นอกจากนี้ยังมีหุบเขาค่าลบเล็กๆ ใกล้กับ $x < 0$ ซึ่งช่วยให้ได้ค่าความชันที่ราบรื่นยิ่งขึ้นในระหว่างการแพร่กระจายย้อนกลับ ช่วยเพิ่มอัตราการลู่เข้าสู่จุดที่เหมาะสมที่สุด (Training Convergence) สำหรับโครงข่ายตรวจจับวัตถุที่มีความลึกได้อย่างมีนัยสำคัญ

```
Act. Output (เอาต์พุต)
  ^
  |        / (SiLU)
  |       /
  |  ____/
  | /    
--v-----------------> Input (อินพุต x)
```

---

## 💻 การเขียนโปรแกรมสาธิตฟังก์ชันกระตุ้นด้วย PyTorch ในภาษา Python (Python PyTorch Activation Demonstration)

```python
import torch
import torch.nn as nn

# Input tensor with negative and positive values
x = torch.tensor([-2.0, -0.5, 0.0, 1.5, 3.0])

# Initialize Activations
relu = nn.ReLU()
leaky_relu = nn.LeakyReLU(negative_slope=0.1)
silu = nn.SiLU()

print(f"Input:      {x.numpy()}")
print(f"ReLU:       {relu(x).numpy()}")
print(f"Leaky ReLU: {leaky_relu(x).numpy()}")
print(f"SiLU:       {silu(x).detach().numpy()}")
```
