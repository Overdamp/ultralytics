# 🧠 EX39: การปรับจูนโมเดลอย่างละเอียด (Fine-Tuning Models)

การปรับจูนอย่างละเอียด (Fine-Tuning) คือกระบวนการนำโมเดลที่ผ่านการฝึกสอนด้วยชุดข้อมูลทั่วไปมาแล้ว (เช่น COCO) มาฝึกสอนเพิ่มเติมด้วยชุดข้อมูลเฉพาะกลุ่มที่มีขนาดเล็กกว่า (เช่น ชุดข้อมูล PTT ของคุณ) โดยใช้อัตราการเรียนรู้ในระดับต่ำ และมักจะมีการตรึงน้ำหนัก (Freeze) ในชั้นแรกๆ เอาไว้

---

## 1. การปรับจูนอย่างละเอียด เทียบกับ การเรียนรู้แบบถ่ายโอน (Fine-Tuning vs. Transfer Learning)
*   **การเรียนรู้แบบถ่ายโอน (Transfer Learning)** คือรูปแบบแนวคิดการออกแบบในภาพกว้าง ในการนำความรู้ที่ได้รับจากงานหนึ่งไปประยุกต์ใช้กับอีกงานหนึ่งที่แตกต่างออกไปแต่มีความเกี่ยวข้องกัน
*   **การปรับจูนอย่างละเอียด (Fine-Tuning)** คือกลยุทธ์การลงมือปฏิบัติเฉพาะเจาะจงของการเรียนรู้แบบถ่ายโอน โดยที่เราจะคงน้ำหนักของโมเดลที่ผ่านการฝึกสอนมาก่อนหน้านี้ไว้ แล้วค่อยๆ อัปเดตน้ำหนักเหล่านั้นอย่างช้าๆ ในระหว่างการฝึกสอนด้วยข้อมูลเฉพาะของเรา

---

## 2. ขั้นตอนการทำงานของการปรับจูนอย่างละเอียด (The Fine-Tuning Workflow)

```
[ โหลดน้ำหนักที่ผ่านการฝึกสอนมาแล้ว ] ---> [ สลับส่วนหัวของการจำแนกประเภท ] ---> [ ตรึงน้ำหนักชั้นโครงข่ายหลัก ] ---> [ ฝึกสอนด้วยอัตราการเรียนรู้ต่ำ ]
```

### ขั้นตอนที่ 1: เปลี่ยนส่วนหัวตัวจำแนกประเภท (Replace the Classifier Head)
เนื่องจากโมเดลที่ฝึกสอนมาก่อนหน้านี้ถูกฝึกด้วยจำนวนคลาสที่แตกต่างกัน (เช่น COCO มี 80 คลาส แต่ชุดข้อมูล PTT ของคุณมี 26 คลาส) เลเยอร์เอาต์พุตสุดท้ายของโครงข่ายจึงจะถูกถอดออกและแทนที่ด้วยส่วนหัวใหม่ที่ถูกกำหนดค่าเริ่มต้นแบบสุ่ม (Randomly Initialized Head) ให้มีจำนวนตรงกับจำนวนคลาสของคุณ

### ขั้นตอนที่ 2: ตรึงน้ำหนักชั้นสกัดคุณลักษณะ (Freeze Feature Extraction Layers - ทางเลือก)
ชั้นแรกๆ ของโครงข่าย (หรือโครงข่ายหลัก - Backbone) ทำหน้าที่ตรวจจับคุณลักษณะทางเรขาคณิตพื้นฐาน เช่น เส้นตรง มุม วงกลม และระดับความเข้มแสง คุณลักษณะเหล่านี้มีความเป็นสากลสูงสำหรับภาพส่วนใหญ่ การ **ตรึงน้ำหนัก (Freezing)** ของชั้นเหล่านี้ (กำหนดให้ `requires_grad = False`) จะช่วยป้องกันไม่ให้กระบวนการแพร่กระจายย้อนกลับ (Backpropagation) เข้าไปแก้ไขน้ำหนักในชั้นดังกล่าว ซึ่งช่วยประหยัดทรัพยากรการคำนวณและลดเวลาการฝึกสอนได้

### ขั้นตอนที่ 3: การเพิ่มประสิทธิภาพด้วยอัตราการเรียนรู้ต่ำ (Low Learning Rate Optimization)
ชั้นโครงข่ายที่เหลือที่ไม่ถูกตรึงน้ำหนักจะถูกฝึกสอนโดยใช้อัตราการเรียนรู้ที่น้อยมาก (โดยทั่วไป $\approx 10^{-4}$ หรือ $10^{-5}$) ซึ่งช่วยป้องกันไม่ให้โมเดลเขียนทับความรู้เก่าที่เคยฝึกสอนมาแล้วรุนแรงเกินไป ซึ่งปัญหาดังกล่าวเรียกว่า **การลืมเลือนอย่างกะทันหัน (Catastrophic Forgetting)**

## 🔬 กรณีศึกษาทางคอมพิวเตอร์วิทัศน์: การตรึงน้ำหนักโครงข่ายหลักของ YOLO (Freezing YOLO Backbone)
เมื่อทำการปรับจูน YOLO อย่างละเอียดบนชุดข้อมูลที่มี 26 คลาสอย่าง [overall-ptt-object-detection.v11i.yolov11](file:///home/luke/ai_training/ultralytics/datasets/coco8/overall-ptt-object-detection.v11i.yolov11) เราสามารถตรึงน้ำหนักของเลเยอร์โครงข่ายหลัก $N$ ชั้นแรกได้ดังนี้:

```python
from ultralytics import YOLO

# Load a pre-trained model
model = YOLO('yolo26n.pt')

# Fine-tune the model, freezing the first 10 layers (the backbone)
# This protects the base feature extraction weights and only trains the neck/head.
model.train(
    data='datasets/coco8/overall-ptt-object-detection.v11i.yolov11/data.yaml',
    epochs=30,
    lr0=0.001,      # Lower learning rate than scratch default (0.01)
    freeze=10       # Freeze first 10 layers
)
```
