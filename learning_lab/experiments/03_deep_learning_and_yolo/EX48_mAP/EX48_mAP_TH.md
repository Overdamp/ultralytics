# 🧠 EX48: ค่าเฉลี่ยความแม่นยำเฉลี่ย (Mean Average Precision - mAP)

ค่าเฉลี่ยความแม่นยำเฉลี่ย (Mean Average Precision - mAP) คือตัววัดค่ามาตรฐานที่ใช้ในการประเมินประสิทธิภาพของโมเดลตรวจจับวัตถุ โดยจะวัดค่าความแม่นยำเฉลี่ยของ bounding box ที่ทำนายได้จากทุกประเภทวัตถุ (classes)

---

## 1. ทำไมถึงไม่ใช้ค่าความถูกต้อง (Accuracy)
ในการตรวจจับวัตถุ โมเดลต้องทำนายทั้ง**ป้ายกำกับคลาส (class label)** และ**พิกัดของ bounding box เชิงพื้นที่ (spatial bounding box coordinates)** ค่าความถูกต้องของการจำแนกประเภทแบบมาตรฐาน (classification accuracy) จึงไม่สามารถตอบโจทย์ได้เนื่องจาก:
*   เราจำเป็นต้องตัดสินว่ากล่องที่ทำนายวางอยู่ในตำแหน่งที่ถูกต้องหรือไม่ (การทับซ้อน)
*   รูปภาพมีสัดส่วนของพิกเซลพื้นหลัง (background pixels) ที่สูงมาก (เกิดปัญหาความไม่สมดุลของคลาสอย่างรุนแรง หรือ class imbalance)

---

## 2. ขั้นตอนการคำนวณ mAP (Step-by-Step mAP Calculation)

ในการคำนวณ mAP เราจะดำเนินการตามขั้นตอนดังต่อไปนี้:

### ขั้นตอนที่ 1: กำหนดการจับคู่ Bounding Box (IoU)
Bounding box ที่ทำนายจะถูกพิจารณาว่าเป็น **ผลบวกจริง (True Positive - TP)** ก็ต่อเมื่อ:
1.  ป้ายกำกับคลาสที่ทำนายตรงกับป้ายกำกับคลาสที่เป็นจริง (ground truth)
2.  ส่วนทับซ้อน (Intersection over Union) กับกล่องที่เป็นจริงมีค่ามากกว่าหรือเท่ากับเกณฑ์ขีดเริ่มเปลี่ยน (เช่น $\text{IoU} \ge 0.5$)
หากไม่เป็นไปตามเงื่อนไขดังกล่าว จะถูกจัดว่าเป็น **ผลบวกเท็จ (False Positive - FP)**

### ขั้นตอนที่ 2: วาดกราฟความแม่นยำเทียบกับความระลึก (Precision-Recall Curve)
สำหรับวัตถุคลาสเดี่ยว:
1.  จัดเรียงผลการทำนายทั้งหมดของโมเดลตามคะแนนความมั่นใจจากมากไปน้อย
2.  คำนวณค่าความแม่นยำ (Precision) และค่าความระลึก (Recall) ไล่ลงมาตามรายการอย่างต่อเนื่อง
3.  นำค่าเหล่านี้มาพล็อตเพื่อสร้าง **เส้นโค้งความแม่นยำและความระลึก (Precision-Recall Curve - PR Curve)**

### ขั้นตอนที่ 3: คำนวณค่าความแม่นยำเฉลี่ย (Average Precision - AP)
AP คือพื้นที่ใต้เส้นโค้ง PR (area under the PR curve) ภายใต้มาตรฐาน COCO ค่านี้จะถูกคำนวณโดยใช้วิธี**การประมาณค่าช่วงแบบทุกจุด (all-point interpolation)**:

$$\text{AP} = \sum_{n} (R_{n+1} - R_n) P_{\text{interp}}(R_{n+1})$$

เมื่อ $P_{\text{interp}}(R) = \max_{\tilde{R} \ge R} P(\tilde{R})$ คือค่าความแม่นยำสูงสุดสำหรับค่าความระลึกใดๆ ที่มีค่ามากกว่า $R$

### ขั้นตอนที่ 4: คำนวณ mAP
mAP คือค่าเฉลี่ยของค่า AP ที่คำนวณได้จากวัตถุทั้งหมด $C$ คลาส:

$$\text{mAP} = \frac{1}{C} \sum_{i=1}^{C} \text{AP}_i$$

---

## 3. รูปแบบต่างๆ ของ mAP ใน YOLO

ในประวัติบันทึก (logs) ของ YOLO (เช่น `results.csv`) คุณจะพบตัวแปรสองรูปแบบดังนี้:
*   **mAP@0.5 (หรือ mAP50):** ค่าเฉลี่ย AP จากทุกคลาสที่คำนวณ ณ เกณฑ์ขีดเริ่มเปลี่ยน IoU ค่าเดียวที่ **0.5** ซึ่งใช้วัดว่าโมเดลสามารถค้นหาและระบุตัวตนของวัตถุได้ดีเพียงใด
*   **mAP@0.5:0.95 (หรือ mAP50-95):** ค่าเฉลี่ย AP ที่เฉลี่ยจากเกณฑ์ขีดเริ่มเปลี่ยน IoU ที่แตกต่างกัน 10 ระดับ (ตั้งแต่ 0.50, 0.55, 0.60, ..., 0.95 โดยเพิ่มขึ้นทีละ 0.05) นี่เป็นตัววัดที่เข้มงวดกว่ามาก ซึ่งใช้วัด**ความแม่นยำในการระบุตำแหน่ง (localization precision)** (ความกระชับของกล่องที่ทำนายเทียบกับวัตถุจริง)

## 🔬 กรณีศึกษาคอมพิวเตอร์วิทัศน์: การประเมินผลชุดข้อมูล PTT
สมมติว่าคุณประเมินโมเดลของคุณบนชุดข้อมูล 26 คลาส [overall-ptt-object-detection.v11i.yolov11](file:///home/luke/ai_training/ultralytics/datasets/coco8/overall-ptt-object-detection.v11i.yolov11)

หากโมเดลตรวจจับได้ผลลัพธ์ดังนี้:
*   `control-valve`: $\text{AP} = 0.90$ (รูปทรงโดดเด่นชัดเจน ตรวจจับได้ง่าย)
*   `small-valve`: $\text{AP} = 0.40$ (มักสับสนกับอุปกรณ์ข้อต่อ/ท่อ)
*   `flange`: $\text{AP} = 0.80$

ค่า mAP ของทั้งสามคลาสนี้คือ:
$$\text{mAP} = \frac{0.90 + 0.40 + 0.80}{3} = 0.70 \quad (70\%)$$

ค่า AP ที่ต่ำในบางคลาสจะบอกคุณได้อย่างชัดเจนว่าคลาสใดที่ต้องการข้อมูลการฝึกสอนเพิ่มเติมหรือจำเป็นต้องปรับจูนไฮเปอร์พารามิเตอร์
