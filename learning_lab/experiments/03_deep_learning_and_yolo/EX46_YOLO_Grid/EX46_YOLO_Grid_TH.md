# 🧠 EX46: ระบบกริดของ YOLO (YOLO Grid System)

ระบบกริดของ YOLO (You Only Look Once) เป็นแนวคิดทางสถาปัตยกรรมที่ช่วยให้สามารถตรวจจับวัตถุแบบขั้นตอนเดียวแบบเรียลไทม์ (real-time single-stage object detection) ได้ โดยการแบ่งรูปภาพออกเป็นเซลล์ย่อยๆ ซึ่งแต่ละเซลล์จะทำหน้าที่ทำนาย bounding box และประเภทของวัตถุพร้อมกัน

---

## 1. แนวคิดพื้นฐานเรื่องระบบกริด

YOLO รุ่นดั้งเดิมจะแบ่งรูปภาพอินพุตออกเป็นกริดเดี่ยว (เช่น $S \times S = 7 \times 7$ หรือ $13 \times 13$)
*   **กฎข้อบังคับของกริดเซลล์ (The Grid Cell Rule):** กริดเซลล์ใดก็ตามที่มีจุดศูนย์กลางของ bounding box ที่แท้จริง (ground truth) ของวัตถุตั้งอยู่ จะเป็นผู้รับผิดชอบในการตรวจจับวัตถุชิ้นนั้น
*   การประเมินกริดในขั้นตอนการป้อนข้อมูลรอบเดียว (single pass) นี้ช่วยขจัดความจำเป็นในการใช้เทคนิคหน้าต่างเลื่อน (sliding windows) ที่มีค่าใช้จ่ายในการคำนวณสูง หรือโครงข่ายเสนอพื้นที่วัตถุ (region proposal networks) (ดังที่ใช้ใน Faster R-CNN)

---

## 2. ความละเอียดกริดแบบหลายสเกลในปัจจุบัน (Modern Multi-Scale Grid Resolution - FPN/PANet Strides)

ในสถาปัตยกรรม YOLO ยุคใหม่ (v8, v11) โมเดลจะไม่ทำนายผลบนกริดเดียวอีกต่อไป แต่จะสกัดแผนที่ฟีเจอร์ที่ระดับความละเอียด (สเกล) แตกต่างกัน 3 ระดับ โดยใช้ระยะก้าว (strides) ขนาด **8, 16, และ 32**:

หากรูปภาพอินพุตมีขนาด $640 \times 640$:

| ระยะก้าว (Stride) | มิติของกริด (Grid Dimensions) | จำนวนเซลล์ (Cell Count) | ขนาดวัตถุเป้าหมาย (Target Object Size) | ตัวอย่างจากชุดข้อมูล PTT |
| :--- | :--- | :--- | :--- | :--- |
| **Stride 8** | $80 \times 80$ | 6,400 เซลล์ | **ขนาดเล็ก (Small)** (รายละเอียดคมชัด) | `small-valve`, `pig-alert`, `digital-gauge` |
| **Stride 16** | $40 \times 40$ | 1,600 เซลล์ | **ขนาดกลาง (Medium)** | `flange`, `lever-handle`, `control-valve` |
| **Stride 32** | $20 \times 20$ | 400 เซลล์ | **ขนาดใหญ่ (Large)** (ฟีเจอร์ระดับกว้าง) | `wellhead`, `xmas-tree`, `pump` |

แต่ละเซลล์ในกริดเหล่านี้จะส่งเอาต์พุตออกมาดังนี้:
1.  **คะแนนการจำแนกประเภท (Classification scores)** สำหรับประเภทวัตถุทั้งหมด 26 คลาส
2.  **ตัวถดถอย Bounding Box (Bounding box regressors)** (แทนระยะทางจากจุดศูนย์กลางเซลล์ไปยังขอบซ้าย ขวา บน และล่างของกล่อง)

---

## 🔬 กรณีศึกษาคอมพิวเตอร์วิทัศน์: การกำหนดตำแหน่งบนกริดแบบหลายสเกล (Multi-Scale Grid Assignment)

สมมติว่ารูปภาพอินพุตประกอบด้วยโครงสร้างแท่นขุดเจาะ `wellhead` ขนาดใหญ่ และอุปกรณ์แจ้งเตือน `pig-alert` ขนาดจิ๋ว:
1.  จุดศูนย์กลางของ `wellhead` จะตกลงในเซลล์บน**กริดขนาด $20 \times 20$ (Stride 32)** โครงข่ายจะใช้เลเยอร์กริดแบบหยาบนี้ในการสร้าง bounding box ขนาดใหญ่ เนื่องจากวัตถุมีอาณาเขตครอบคลุมพื้นที่เชิงตำแหน่งที่กว้างใหญ่มาก
2.  จุดศูนย์กลางของ `pig-alert` จะตกลงในเซลล์บน**กริดขนาด $80 \times 80$ (Stride 8)** ความละเอียดสูงของกริดนี้มีความจำเป็นอย่างยิ่งสำหรับการตรวจจับลักษณะระดับพิกเซลขนาดจิ๋วของสวิตช์แจ้งเตือนโดยไม่ทำให้ฟีเจอร์เหล่านี้สูญหายไประหว่างการลดขนาดข้อมูล (downsampling)
