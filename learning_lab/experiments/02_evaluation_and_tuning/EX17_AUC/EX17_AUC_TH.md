# 🧠 EX17: พื้นที่ใต้เส้นโค้ง (Area Under the Curve หรือ AUC)

AUC (Area Under the ROC Curve - พื้นที่ใต้เส้นโค้ง ROC) คือมาตรวัดพื้นที่สองมิติทั้งหมดที่อยู่ใต้เส้นโค้ง ROC ซึ่งเป็นค่าสรุปประสิทธิภาพโดยรวมของตัวจำแนกประเภทในทุกระดับเกณฑ์การจำแนกประเภทที่เป็นไปได้

---

## 1. สูตรทางคณิตศาสตร์

ทางคณิตศาสตร์ AUC นิยามด้วยอินทิกรัลของอัตราผลบวกจริง (TPR/Recall) เทียบกับอัตราผลบวกเท็จ (FPR):

$$\text{AUC} = \int_{0}^{1} \text{TPR}(\text{FPR}) \, d\text{FPR}$$

เนื่องจาก $\text{TPR}$ และ $\text{FPR}$ ถูกจำกัดค่าอยู่ระหว่าง $0$ ถึง $1$ ค่า AUC จึงถูกจำกัดอยู่ระหว่าง $0$ ถึง $1$ เสมอ:

| ค่า AUC | การตีความ |
| :--- | :--- |
| **$\text{AUC} = 1.0$** | **ตัวจำแนกประเภทที่สมบูรณ์แบบ (Perfect Classifier):** โมเดลแยกคลาสบวกและลบออกด้วยความแม่นยำ $100\%$ (ไม่มีการซ้อนทับกันของรูปร่างการแจกแจงข้อมูล) |
| **$0.5 < \text{AUC} < 1.0$** | **ตัวจำแนกประเภทที่ใช้งานได้จริง (Realistic Classifier):** โมเดลมีความสามารถในการแยกแยะในระดับที่ดี (ค่ายิ่งสูงยิ่งดี) |
| **$\text{AUC} = 0.5$** | **การเดาสุ่ม (Random Guessing):** โมเดลไม่มีความสามารถในการจำแนกประเภทเลย (เทียบเท่ากับการโยนเหรียญหัวก้อย) |
| **$\text{AUC} < 0.5$** | **ตัวจำแนกประเภทสลับขั้ว (Reciprocal Classifier):** โมเดลทำนายกลับหัวเป็นก้อย (แก้ไขได้โดยการกลับทิศทางคำทำนาย) |

---

## 2. การตีความเชิงกายภาพและเชิงความน่าจะเป็น

ในทางคณิตศาสตร์ AUC มีค่าเท่ากับความน่าจะเป็นที่ตัวจำแนกประเภทจะจัดอันดับคะแนนของ **ตัวอย่างคลาสบวกที่สุ่มเลือกขึ้นมา** ให้สูงกว่า **ตัวอย่างคลาสลบที่สุ่มเลือกขึ้นมา**:

$$P\left( f(x^+) > f(x^-) \right)$$

ตัวอย่างเช่น หากค่า $\text{AUC}$ ของโมเดลเท่ากับ $0.90$ หมายความว่าเมื่อให้ภาพคลาสบวกแบบสุ่ม (เช่น ภาพที่มี `lever-valve`) และภาพคลาสลบแบบสุ่ม (เช่น ท่อหรือหญ้าบนพื้นหลัง) จะมี **โอกาส $90\%$** ที่โมเดลจะให้คะแนนความเชื่อมั่น (Confidence score) แก่วาล์วสูงกว่าพื้นหลัง

---

## 3. ข้อดีของ AUC
1.  **ไม่ขึ้นกับสเกล (Scale-Invariant):** วัดความสามารถในการ **จัดอันดับ** ของผลการทำนายแทนที่จะเป็นค่าสัมบูรณ์ (เช่น หากคุณคูณผลการทำนายทั้งหมดด้วย 2 ค่า AUC ก็จะยังคงเหมือนเดิมทุกประการ)
2.  **ไม่ขึ้นกับเกณฑ์จำแนกประเภท (Classification-Threshold-Invariant):** วัดคุณภาพโดยรวมของโมเดล โดยไม่เกี่ยงว่าจะเลือกเกณฑ์เฉพาะเจาะจงใด (เช่น `0.5` หรือ `0.8`) มาใช้ในการตัดสินใจขั้นสุดท้าย

## 💻 การคำนวณคะแนน AUC ด้วย Python

นี่คือวิธีการคำนวณคะแนน AUC โดยใช้ Scikit-Learn:

```python
import numpy as np
from sklearn.metrics import roc_auc_score

# Ground truth binary labels (1 = positive class, 0 = negative class)
y_true = np.array([1, 0, 1, 1, 0, 1, 0, 0, 1, 0])

# Raw prediction scores (probabilities output by the model)
y_scores = np.array([0.9, 0.1, 0.8, 0.7, 0.2, 0.85, 0.4, 0.1, 0.65, 0.3])

# Calculate AUC Score
auc_score = roc_auc_score(y_true, y_scores)
print(f"AUC Score: {auc_score:.4f}")  # Outputs 0.96 (Excellent separability)
```
