# 🧠 EX19: การทดสอบความถูกต้องไขว้ (Cross-Validation)

การทดสอบความถูกต้องไขว้ (Cross-Validation) คือเทคนิคการสุ่มข้อมูลซ้ำ (Resampling) ที่ใช้ในการประเมินความสามารถในการสรุปผลทั่วไป (Generalization) ของโมเดลบนชุดข้อมูลที่จำกัด เทคนิคนี้ช่วยป้องกันการเรียนรู้เกิน (Overfitting) และทำให้มั่นใจได้ว่ามาตรวัดประสิทธิภาพในการตรวจสอบจะไม่เกิดความเอนเอียง (Bias) จากการแบ่งข้อมูลฝึกสอน-ตรวจสอบที่บังเอิญโชคดีเพียงครั้งเดียว

---

## 1. ขั้นตอนการทำ K-Fold Cross-Validation ทีละขั้นตอน

ใน $K$-Fold Cross-Validation ชุดข้อมูลจะถูกแบ่งออกเป็น $K$ ส่วนย่อยที่มีขนาดเท่าๆ กัน (เรียกว่า พับ หรือ Folds):

```
การแบ่งพับข้อมูล (Dataset Folds):
รอบที่ 1:  [ ตรวจสอบ ] [ ฝึกสอน ] [ ฝึกสอน ] [ ฝึกสอน ] [ ฝึกสอน ] -> mAP_1
รอบที่ 2:  [ ฝึกสอน ] [ ตรวจสอบ ] [ ฝึกสอน ] [ ฝึกสอน ] [ ฝึกสอน ] -> mAP_2
รอบที่ 3:  [ ฝึกสอน ] [ ฝึกสอน ] [ ตรวจสอบ ] [ ฝึกสอน ] [ ฝึกสอน ] -> mAP_3
...
```

1.  แบ่งข้อมูลแบบสุ่มออกเป็น $K$ ส่วนย่อย (โดยทั่วไปจะตั้งค่า $K=5$ หรือ $K=10$)
2.  ฝึกสอนโมเดลด้วยส่วนย่อยจำนวน $K-1$ ส่วนที่นำมารวมกัน
3.  ประเมินผลโมเดลด้วยส่วนย่อยอีก 1 ส่วนที่เหลืออยู่ (ซึ่งทำหน้าที่เป็นชุดตรวจสอบ หรือ Validation set)
4.  ทำซ้ำขั้นตอนข้างต้นทั้งหมด $K$ ครั้ง โดยเปลี่ยนส่วนย่อยที่ใช้เป็นชุดตรวจสอบไม่ให้ซ้ำกันในแต่ละรอบ
5.  หาค่าเฉลี่ยของคะแนนประเมินผลทั้ง $K$ ครั้ง เพื่อนำมาเป็นมาตรวัดประสิทธิภาพสุดท้าย:

$$\text{mAP}_{\text{final}} = \frac{1}{K} \sum_{i=1}^{K} \text{mAP}_i$$

---

## 2. Stratified K-Fold (มาตรฐานของการจำแนกประเภท)
เมื่อต้องจัดการกับชุดข้อมูลที่มีความไม่สมดุลของคลาส (เช่น คลาสหนึ่งมีสัดส่วนเพียง $2\%$ ของข้อมูลทั้งหมด) การแบ่งข้อมูลแบบสุ่มทั่วไปอาจส่งผลให้บางพับไม่มีข้อมูลของคลาสนั้นๆ ปรากฏอยู่เลย 

**Stratification (การแบ่งชั้น)** จะช่วยรับประกันว่าในแต่ละพับจะมีสัดส่วนเปอร์เซ็นต์ของตัวอย่างในแต่ละคลาสใกล้เคียงกับสัดส่วนในชุดข้อมูลทั้งหมด ซึ่งช่วยรักษาความครอบคลุมและเป็นตัวแทนที่ดีในระหว่างการฝึกสอน

## 🔬 กรณีศึกษาของวิสัยทัศน์คอมพิวเตอร์: K-Fold ใน YOLO
ในการเรียนรู้เชิงลึก (Deep learning) โดยเฉพาะอย่างยิ่งการตรวจจับวัตถุ (Object detection) การทำ $K$-Fold Cross-Validation แบบเต็มรูปแบบนั้น **ไม่ค่อยนิยมใช้กับชุดข้อมูลขนาดใหญ่** เนื่องจากจะทำให้ระยะเวลาฝึกสอนและต้นทุนการคำนวณเพิ่มขึ้นถึง $K$ เท่า (เช่น ต้องฝึกสอนโมเดลแยกกันถึง 5 โมเดลแทนที่จะเป็นโมเดลเดียว)

อย่างไรก็ตาม เทคนิคนี้เหมาะและแนะนำอย่างยิ่งเมื่อ:
1.  **ชุดข้อมูลมีขนาดเล็ก:** คุณมีภาพจำนวนจำกัดและต้องการป้องกันไม่ให้ผลประเมินเกิดความเอนเอียง
2.  **การค้นหาไฮเปอร์พารามิเตอร์ (Hyperparameter Search):** เพื่อค้นหาพารามิเตอร์ที่เสถียรที่สุดก่อนเริ่มรันการฝึกสอนรอบสุดท้าย

### สคริปต์ Python สำหรับแบ่งชุดข้อมูลแบบ K-Fold:
โค้ดด้านล่างนี้แสดงวิธีการแบ่งภาพและป้ายกำกับออกเป็นพับย่อยๆ โดยใช้ไลบรารี `sklearn`:

```python
from sklearn.model_selection import KFold
import glob
import os

# Get all images in custom dataset
image_files = sorted(glob.glob('datasets/coco8/overall-ptt-object-detection.v11i.yolov11/train/images/*.jpg'))

kf = KFold(n_splits=5, shuffle=True, random_state=42)

for fold, (train_idx, val_idx) in enumerate(kf.split(image_files)):
    print(f"--- Fold {fold + 1} ---")
    print(f"Number of training samples: {len(train_idx)}")
    print(f"Number of validation samples: {len(val_idx)}")
    # In practice, you copy these files to folders/fold_i and generate data_fold_i.yaml
```
