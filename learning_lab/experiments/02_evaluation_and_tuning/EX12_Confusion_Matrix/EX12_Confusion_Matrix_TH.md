# 🧠 EX12: เมทริกซ์ความสับสน (Confusion Matrix)

เมทริกซ์ความสับสน (Confusion Matrix) คือตารางการประเมินประสิทธิภาพที่ใช้ในการเรียนรู้ของเครื่องแบบมีผู้สอน (Supervised machine learning) ตารางนี้จะแสดงผลการทำนายที่ถูกต้องควบคู่ไปกับความผิดพลาดของโมเดล (การเตือนลวง, การตรวจจับพลาด และความสับสนระหว่างคลาส) ทำให้เห็นได้ง่ายว่าโมเดลกำลังสับสนระหว่างคลาสใดคลาสหนึ่งโดยเฉพาะหรือไม่

---

## 1. รูปแบบของเมทริกซ์ความสับสนแบบสองกลุ่ม (Binary Confusion Matrix)
สำหรับการจำแนกประเภทแบบสองกลุ่ม (Binary classification) เมทริกซ์จะเป็นตารางขนาด $2\times2$ ดังนี้:

| | ทำนายว่าเป็นบวก (1) | ทำนายว่าเป็นลบ (0) |
| :--- | :--- | :--- |
| **ค่าจริงเป็นบวก (1)** | **ผลบวกจริง (TP):** ทำนายคลาสบวกถูกต้อง | **ผลลบเท็จ (FN):** ตรวจจับพลาด (ความผิดพลาดประเภทที่ 2) |
| **ค่าจริงเป็นลบ (0)** | **ผลบวกเท็จ (FP):** เตือนลวง (ความผิดพลาดประเภทที่ 1) | **ผลลบจริง (TN):** ทำนายคลาสลบถูกต้อง |

---

## 2. การขยายผลสู่การตรวจจับวัตถุหลายคลาส (การจัดการกับพื้นหลัง)
ในการตรวจจับวัตถุ (Object detection) เราต้องจำแนกประเภทวัตถุหลายประเภท (เช่น 26 คลาสในชุดข้อมูล PTT ของคุณ) และต้องคำนึงถึงพิกเซลที่เป็นพื้นหลัง (Background) ด้วย:
*   จะมีการเพิ่ม **"คลาสพื้นหลัง" (Background class)** เข้าไปเป็นแถวและคอลัมน์พิเศษในเมทริกซ์
*   **ทำนายว่าเป็นพื้นหลัง (คู่แถว):** หากตรวจไม่พบ `control-valve` จริงโดย YOLO ค่าดังกล่าวจะถูกนับในคอลัมน์ `Background` (ผลลบเท็จ / วัตถุที่ตรวจจับพลาด)
*   **ค่าจริงเป็นพื้นหลัง (คู่คอลัมน์):** หาก YOLO วาดกรอบล้อมรอบสิ่งกีดขวางที่เป็นเหล็กบนพื้นหลังและป้ายกำกับว่าเป็น `flange` ค่าดังกล่าวจะถูกนับในแถว `Background` (ผลบวกเท็จ / การเตือนลวง)

---

## 3. เมทริกซ์ความสับสนแบบมาตรฐาน (Normalized) เทียบกับแบบดิบ (Raw)
*   **เมทริกซ์แบบดิบ (Raw Matrix):** แสดงจำนวนเต็มของการทำนาย (เช่น ทำนายว่าเป็นคลาส A จำนวน 45 ครั้ง, เป็นคลาส B จำนวน 3 ครั้ง) ซึ่งจำนวนตัวอย่างในคลาสอาจเข้ามามีอิทธิพลหลักต่อรูปตารางได้
*   **เมทริกซ์แบบมาตรฐาน (Normalized Matrix):** นำแต่ละแถวไปหารด้วยผลรวมของตัวอย่างจริงในคลาสนั้นๆ (ผลรวมของแต่ละแถวจะเท่ากับ `1.0` หรือ `100%`) วิธีนี้จะแสดงเปอร์เซ็นต์ความถูกต้องของแต่ละคลาสโดยไม่ขึ้นกับขนาดของชุดข้อมูล

## 💻 การคำนวณเมทริกซ์ความสับสนหลายคลาสด้วย Python

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay

# True labels of 3 classes: 0=flange, 1=valve, 2=gauge
y_true = np.array([0, 1, 2, 0, 1, 2, 0, 2, 1, 1, 0, 2, 2, 1])

# Model predictions
y_pred = np.array([0, 1, 1, 0, 1, 2, 0, 1, 1, 2, 0, 2, 2, 1])  # Confuses gauge (2) as valve (1)

# Generate raw confusion matrix
cm = confusion_matrix(y_true, y_pred)

# Display the matrix
disp = ConfusionMatrixDisplay(confusion_matrix=cm, display_labels=['flange', 'valve', 'gauge'])
disp.plot(cmap=plt.cm.Blues)
plt.title("PTT Multi-Class Confusion Matrix")
plt.savefig('learning_lab/experiments/02_evaluation_and_tuning/EX12_Confusion_Matrix/confusion_matrix_plot.png')
print("Confusion Matrix plot saved.")
```
