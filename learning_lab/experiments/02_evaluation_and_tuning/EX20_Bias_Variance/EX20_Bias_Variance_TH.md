# 🧠 EX20: การประนีประนอมความเอนเอียงและความแปรปรวน (Bias-Variance Tradeoff)

การประนีประนอมความเอนเอียงและความแปรปรวน (Bias-Variance Tradeoff) คือแนวคิดพื้นฐานในการเรียนรู้ของเครื่อง (Machine learning) ที่อธิบายถึงความขัดแย้งระหว่างความสามารถของโมเดลในการสรุปผลทั่วไปสู่ข้อมูลใหม่ เทียบกับความสามารถในการเรียนรู้รูปแบบจากข้อมูลฝึกสอน

---

## 1. นิยามหลัก

*   **ความเอนเอียง (Bias):** ค่าความคลาดเคลื่อนที่เกิดจากการพยายามประมาณปัญหาในโลกจริงที่มีความซับซ้อน ด้วยโมเดลที่ง่ายเกินไป ค่าความเอนเอียงที่สูงจะนำไปสู่ **การเรียนรู้ต่ำกว่าเกณฑ์ (Underfitting)** (โมเดลเรียบง่ายเกินไปจนไม่สามารถตรวจจับโครงสร้างเบื้องลึกของข้อมูลได้)
*   **ความแปรปรวน (Variance):** ค่าความคลาดเคลื่อนที่เกิดจากความไวของโมเดลต่อความผันผวนเล็กๆ น้อยๆ ในชุดข้อมูลฝึกสอน ค่าความแปรปรวนที่สูงจะนำไปสู่ **การเรียนรู้เกิน (Overfitting)** (โมเดลเรียนรู้และจดจำสัญญาณรบกวน (Noise) ในชุดข้อมูลฝึกสอนเสมือนว่าเป็นรูปแบบทั่วไปของข้อมูล)

---

## 2. การย่อยสลายค่าความคลาดเคลื่อนทางคณิตศาสตร์

สำหรับตัวแปรเป้าหมาย $y = f(x) + \epsilon$ (โดยที่ $\epsilon$ คือสัญญาณรบกวนแบบสุ่มที่มีค่าเฉลี่ยเป็นศูนย์และความแปรปรวนเท่ากับ $\sigma^2$) ค่าความคลาดเคลื่อนกำลังสองที่คาดหวังในการทำนาย (Expected squared prediction error) ของโมเดล $\hat{f}(x)$ สามารถย่อยสลายทางคณิตศาสตร์ออกเป็นสามส่วนได้ดังนี้:

$$\text{Expected Prediction Error} = \text{Bias}[\hat{f}(x)]^2 + \text{Variance}[\hat{f}(x)] + \sigma^2$$

### องค์ประกอบต่างๆ:
1.  **พจน์ความเอนเอียง (Bias term):**
    $$\text{Bias}[\hat{f}(x)] = \mathbb{E}[\hat{f}(x)] - f(x)$$
    (ความแตกต่างระหว่างผลการทำนายเฉลี่ยของโมเดลกับค่าจริง)
2.  **พจน์ความแปรปรวน (Variance term):**
    $$\text{Variance}[\hat{f}(x)] = \mathbb{E}\left[ \left(\hat{f}(x) - \mathbb{E}[\hat{f}(x)]\right)^2 \right]$$
    (ความแตกต่างผันผวนของผลการทำนายของโมเดลเมื่อเปลี่ยนชุดข้อมูลฝึกสอนชุดต่างๆ)
3.  **ค่าความคลาดเคลื่อนที่ลดทอนไม่ได้ (Irreducible Error: $\sigma^2$):** สัญญาณรบกวนที่ติดมากับตัวข้อมูลเองโดยธรรมชาติ (เช่น ความผิดพลาดในการป้ายกำกับ หรือสัญญาณรบกวนจากเซ็นเซอร์) ซึ่งไม่สามารถลดทอนลงได้ไม่ว่าจะใช้โมเดลใดๆ ก็ตาม

---

## 3. การค้นหาความซับซ้อนที่เหมาะสมที่สุด (Optimal Complexity)

เมื่อความซับซ้อนของโมเดลเพิ่มขึ้น (เช่น การเพิ่มชั้นซ่อน (Hidden layers), การฝึกสอนนานขึ้น หรือการเพิ่มคุณลักษณะ (Features) ของข้อมูล):
*   **ค่าความเอนเอียงจะลดลง** (โมเดลปรับตัวเข้ากับข้อมูลฝึกสอนได้ดีขึ้น)
*   **ค่าความแปรปรวนจะเพิ่มขึ้น** (โมเดลเริ่มอ่อนไหวและตอบสนองต่อสัญญาณรบกวนในข้อมูลฝึกสอน)

ค่าความคลาดเคลื่อนรวมจะแสดงเป็น **กราฟรูปตัว U** เป้าหมายของเราคือการค้นหาจุดต่ำสุดของเส้นโค้งนี้:

```
ความคลาดเคลื่อน
  ^
  |     \  ค่าความคลาดเคลื่อนรวม  /  <-- ค่าความคลาดเคลื่อนต่ำสุด (จุดที่เหมาะสมที่สุด)
  |      \    ________   /
  |  ความ \  /        \ /  ความ
  |เอนเอียง\/          v แปรปรวน
  |  สูง                 สูง
  |________/_____________\_____
  0      ต่ำ             สูง      ความซับซ้อนของโมเดล (Model Complexity)
```

## 🔬 กรณีศึกษาของวิสัยทัศน์คอมพิวเตอร์: การเลือกขนาดโมเดล YOLO
การเลือกขนาดโมเดล YOLO ที่จะนำมาฝึกสอนบนชุดข้อมูล PTT ของคุณ ถือเป็นตัวอย่างโดยตรงของการประนีประนอมระหว่างความเอนเอียงและความแปรปรวน:

*   **ความเอนเอียงสูง (Underfitting):** หากคุณฝึกสอนโมเดลขนาดเล็กที่สุดอย่าง `yolo26n.pt` เพียงแค่ 5 รอบ (Epochs) บนชุดข้อมูลขนาดใหญ่ โมเดลจะตรวจจับวัตถุขนาดเล็ก (เช่น `small-valves`) ได้ยากมาก ส่งผลให้ค่า mAP ทั้งในชุดฝึกสอนและชุดตรวจสอบมีค่าต่ำทั้งคู่
*   **ความแปรปรวนสูง (Overfitting):** หากคุณฝึกสอนโมเดลขนาดใหญ่อย่าง `yolo26x.pt` บนชุดข้อมูลที่มีขนาดเล็กมาก (เช่น มีภาพเพียง 100 ภาพ) นานถึง 300 รอบ โมเดลอาจจะทำค่า mAP ได้สูงถึง $99\%$ บนชุดฝึกสอน แต่เมื่อนำไปทดสอบกับชุดทดสอบจริง ค่า mAP อาจดิ่งลงเหลือเพียง $30\%$ เนื่องจากโมเดลใช้วิธีท่องจำรายละเอียดของพื้นหลัง ฝุ่นผง หรือสภาพแสงในรูปภาพฝึกสอน แทนที่จะเรียนรู้ลักษณะรูปทรงทั่วไปของวัตถุ
