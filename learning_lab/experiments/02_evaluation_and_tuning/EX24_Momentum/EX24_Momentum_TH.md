# 🧠 EX24: การเพิ่มประสิทธิภาพด้วยโมเมนตัม (Momentum Optimization)

โมเมนตัม (Momentum) คือเทคนิคการเพิ่มประสิทธิภาพที่ช่วยเร่งการลู่เข้าของ Gradient Descent โดยการสะสมความเร็วในทิศทางของเกรเดียนต์ที่มีความสม่ำเสมอ ช่วยลดการแกว่งตัว (Oscillations) และช่วยให้โมเดลหลุดพ้นจากค่าต่ำสุดเฉพาะกลุ่ม (Local minima) ได้

---

## 1. การเปรียบเทียบทางกายภาพ: ลูกบอลที่กำลังกลิ้ง (The Physical Analogy: A Rolling Ball)
Gradient Descent แบบมาตรฐานเปรียบเสมือนคนที่กำลังเดินทีละก้าว ซึ่งจะประเมินความชันที่เท้าของตนเองแล้วก้าวเดิน โดยจะลืมความเร็วของก้าวก่อนหน้าไปทันที หากความชันเปลี่ยนทิศทาง เขาก็จะเลี้ยวเปลี่ยนทิศทางในทันที

**โมเมนตัม (Momentum)** จะทำหน้าที่เหมือนลูกบอลหนักๆ ที่กำลังกลิ้งลงเขา:
*   ขณะที่ลูกบอลกลิ้ง มันจะสะสมความเร็วจากแรงโน้มถ่วง (เกรเดียนต์)
*   มวลของลูกบอล (โมเมนตัม) จะป้องกันไม่ให้มันหยุดนิ่งในทันทีเมื่อถึงบริเวณที่เป็นทางราบ ช่วยให้มันกลิ้งผ่านหุบเขาที่ราบเรียบและหลุดพ้นจากค่าต่ำสุดเฉพาะกลุ่มที่ตื้นเขินได้

---

## 2. การลดการแกว่งตัวในหุบเหวชัน (Dampening Oscillations in Ravines)
ในพื้นผิวฟังก์ชันการสูญเสียที่ซับซ้อน (เช่น หุบเหวที่ลาดชัน) SGD แบบมาตรฐานจะแกว่งตัวไปมาระหว่างผนังที่ชันทั้งสองด้าน แทนที่จะเคลื่อนที่ไปตามพื้นหุบเขาเพื่อมุ่งสู่จุดต่ำสุด:

```text
SGD (แกว่งตัว):                      Momentum (ราบรื่น):
   \    /\    /\    /                  \              /
    \  /  \  /  \  /                    \------------> (เคลื่อนที่ไปตามพื้นหุบเขาอย่างราบรื่น)
     \/    \/    \/                      \          /
```

การใช้โมเมนตัมจะช่วยให้ส่วนประกอบที่แกว่งไปมาของการอัปเดตเกรเดียนต์หักล้างกันเองเมื่อเวลาผ่านไป ในขณะที่ส่วนประกอบที่ชี้ไปตามแนวพื้นหุบเขาจะเสริมความแข็งแกร่งซึ่งกันและกัน ส่งผลให้เกิดการลู่เข้าที่เร็วขึ้นและราบรื่นขึ้น

---

## 3. สูตรทางคณิตศาสตร์ (Mathematical Formulation)

ในแต่ละการวนซ้ำ (Iteration) $t$:

### ขั้นตอนที่ 1: คำนวณความเร็ว ($v_t$)
เราเพิ่มเศษส่วน $\beta$ ของความเร็วก่อนหน้าเข้าไปในการอัปเดตเกรเดียนต์ปัจจุบัน:

$$\mathbf{v}_t = \beta \mathbf{v}_{t-1} + \alpha \nabla J(\mathbf{w}_t)$$

โดยที่:
*   $\\beta \\in [0, 1]$ คือ **ปัจจัยโมเมนตัม (Momentum factor)** (ทำหน้าที่เสมือนแรงเสียดทาน) หาก $\beta = 0.9$ หมายความว่าในก้าวปัจจุบันจะยังคงรักษาความเร็ว $90\%$ ของความเร็วก่อนหน้าไว้
*   $\alpha$ คืออัตราการเรียนรู้ (Learning Rate)
*   $\nabla J(\mathbf{w}_t)$ คือเกรเดียนต์

### ขั้นตอนที่ 2: อัปเดตค่าน้ำหนัก (Update Weights)
$$\mathbf{w}_{t+1} = \mathbf{w}_t - \mathbf{v}_t$$

---

## 💡 การไล่ตามความชันแบบเร่งของเนสเทรอฟ (Nesterov Accelerated Gradient - NAG)
Nesterov Momentum คือการเพิ่มประสิทธิภาพในรูปแบบ "มองล่วงหน้า" (Look-ahead) แทนที่จะคำนวณเกรเดียนต์ ณ ตำแหน่งปัจจุบัน $\mathbf{w}_t$ ขั้นตอนนี้จะคำนวณเกรเดียนต์ ณ ตำแหน่งที่คาดการณ์ไว้ล่วงหน้า $\mathbf{w}_t - \beta \mathbf{v}_{t-1}$:

$$\mathbf{v}_t = \beta \mathbf{v}_{t-1} + \alpha \nabla J(\mathbf{w}_t - \beta \mathbf{v}_{t-1})$$

สิ่งนี้ทำหน้าที่เป็นเสมือนระบบเบรกอัจฉริยะ หากโมเมนตัมกำลังจะพาโมเดลขึ้นไปบนเนินเขาที่ลาดชันฝั่งตรงข้าม เกรเดียนต์ที่มองล่วงหน้าจะตรวจพบทิศทางขึ้นเขานี้ได้ล่วงหน้า และชะลอการอัปเดตเพื่อป้องกันการก้าวเดินเลยจุดต่ำสุด (Overshooting)

---

## 🔬 ความเชื่อมโยงกับการมองเห็นของคอมพิวเตอร์: โมเมนตัมของตัวปรับปรุงประสิทธิภาพ YOLO (YOLO Optimizer Momentum)
ในการฝึกสอนโมเดล YOLO (เช่นในบันทึกการตั้งค่าการฝึกสอนของ `train-3`) ค่าโมเมนตัมของตัวปรับปรุงประสิทธิภาพ SGD จะมีค่าเริ่มต้นเป็น `momentum=0.937` ค่านี้ได้รับการปรับปรุงประสิทธิภาพมาอย่างดีเพื่อสร้างสมดุลระหว่างความเร็วในการลู่เข้าและป้องกันไม่ให้ค่าน้ำหนักลู่ออก (Diverge) บนชุดข้อมูลที่กำหนดเอง
