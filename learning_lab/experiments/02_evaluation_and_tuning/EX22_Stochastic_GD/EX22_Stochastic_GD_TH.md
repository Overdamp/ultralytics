# 🧠 EX22: การไล่ตามความชันแบบสุ่ม (Stochastic Gradient Descent - SGD)

การไล่ตามความชันแบบสุ่ม (Stochastic Gradient Descent หรือ SGD) คือขั้นตอนวิธีในการเพิ่มประสิทธิภาพ (Optimization algorithm) ที่ทำการอัปเดตน้ำหนักของโมเดลหลังจากประเมินตัวอย่างข้อมูลฝึกสอน **เพียงตัวอย่างเดียวที่ถูกเลือกแบบสุ่ม** วิธีการนี้จะเพิ่มสัญญาณรบกวนแบบสุ่ม (Stochastic/Random noise) ซึ่งช่วยเร่งการคำนวณให้เร็วขึ้นและช่วยให้หลุดพ้นจากค่าต่ำสุดเฉพาะกลุ่ม (Local minima) ได้

---

## 1. ทำไมต้องใช้ SGD? (ปัญหาของ Batch GD)
ใน **Batch Gradient Descent** แบบมาตรฐาน โมเดลจำเป็นต้องคำนวณเกรเดียนต์สำหรับ *ทุกๆ ตัวอย่างข้อมูลฝึกสอน* ในชุดข้อมูลก่อนที่จะสามารถอัปเดตน้ำหนักได้เพียงครั้งเดียว
*   หากชุดข้อมูลของคุณมีรูปภาพ 1,000,000 ภาพ การก้าวเดินของ Gradient Descent เพียงก้าวเดียวจะต้องใช้วงรอบการทำงานไปข้างหน้า (Forward pass) และย้อนกลับ (Backward pass) ถึง 1,000,000 ครั้ง
*   ซึ่งเป็นเรื่องที่สิ้นเปลืองทรัพยากรการคำนวณอย่างมากและทำให้การฝึกสอนล่าช้า

SGD แก้ปัญหานี้โดยการคำนวณเกรเดียนต์และอัปเดตน้ำหนักทันทีหลังจากประมวลผลข้อมูล **หนึ่ง** ตัวอย่าง

---

## 2. สูตรทางคณิตศาสตร์ (Mathematical Formulation)

สำหรับตัวอย่างข้อมูลฝึกสอนเดียวที่ถูกเลือก $(x^{(i)}, y^{(i)})$ เราจะกำหนดฟังก์ชันการสูญเสียของตัวอย่างเดี่ยว (Single-sample loss) ดังนี้:

$$J^{(i)}(w, b) = \frac{1}{2} \left( h_{w,b}(x^{(i)}) - y^{(i)} \right)^2$$

การอัปเดตเกรเดียนต์จะดำเนินการทันที:

$$w \leftarrow w - \alpha \left( h_{w,b}(x^{(i)}) - y^{(i)} \right) \cdot x^{(i)}$$
$$b \leftarrow b - \alpha \left( h_{w,b}(x^{(i)}) - y^{(i)} \right)$$

โดยที่:
*   $\alpha$ คืออัตราการเรียนรู้ (Learning Rate)
*   $h_{w,b}(x^{(i)}) - y^{(i)}$ คือความคลาดเคลื่อนในการพยากรณ์ (Prediction error)

---

## 3. บทบาทของสัญญาณรบกวนแบบสุ่ม (The Role of Stochastic Noise)
เนื่องจากแต่ละตัวอย่างข้อมูลฝึกสอนจะให้ค่าประมาณของเกรเดียนต์จริงของชุดข้อมูลทั้งหมดที่มีสัญญาณรบกวน (Noise) ค่าน้ำหนักจึงเคลื่อนที่ในเส้นทางที่คดเคี้ยวและไม่สม่ำเสมอ (คล้ายกับการเดินสุ่ม หรือ Random walk) เพื่อมุ่งสู่จุดต่ำสุด:

```
Loss Surface
  \
   \     /\     /\     /\
    \___/  \___/  \___/  \---> จุดต่ำสุด (เส้นทางที่มีสัญญาณรบกวนช่วยในการกระโดดข้ามพื้นที่ราบ)
```

*   **การทำให้เป็นระเบียบ (Regularization):** สัญญาณรบกวนนี้ทำหน้าที่เสมือนตัวช่วยควบคุม (Regularizer) ป้องกันไม่ให้โมเดลปรับตัวเข้ากับสัญญาณรบกวนเร็วเกินไป และช่วยให้มัน "กระโดด" หลุดออกจากจุดต่ำสุดเฉพาะกลุ่มที่ตื้นเขินหรือจุดอานม้าได้
*   **ปัญหาการลู่เข้า (The Convergence Problem):** เนื่องจากสัญญาณรบกวนดังกล่าว SGD จะไม่มีทางหยุดนิ่งตรงจุดต่ำสุดสัมบูรณ์อย่างแม่นยำ แต่จะกระดอนไปมาอยู่รอบๆ จุดนั้นแทน
*   **แนวทางแก้ไข:** เราต้องค่อยๆ ปรับลดอัตราการเรียนรู้ลงเมื่อเวลาผ่านไป (โดยการใช้ตัวกำหนดตารางเวลาอัตราการเรียนรู้ เช่น Cosine Annealing) เพื่อให้ขนาดของก้าวเล็กลงเรื่อยๆ และโมเดลสามารถหยุดนิ่งอยู่ใกล้จุดต่ำสุดได้มากที่สุด

## 💻 การเขียนโปรแกรมลูปของ SGD ด้วย Python (เริ่มต้นใหม่ทั้งหมด)

```python
import numpy as np

# Mock inputs (X) and targets (y)
X = np.array([[1.0], [2.0], [3.0], [4.0]])
y = np.array([[2.0], [4.0], [6.0], [8.0]]) # True relationship: y = 2 * x

# Initialize parameters
w = 0.0
b = 0.0
lr = 0.01

# Run SGD for 5 epochs
for epoch in range(5):
    # Randomly shuffle data indices to ensure stochastic property
    indices = np.random.permutation(len(X))
    for idx in indices:
        xi = X[idx]
        yi = y[idx]
        
        # Forward pass (single sample prediction)
        prediction = w * xi + b
        
        # Compute single sample gradient
        error = prediction - yi
        dw = error * xi
        db = error
        
        # Immediate update
        w -= lr * dw
        b -= lr * db
        
    print(f"Epoch {epoch+1}: Weight = {w[0]:.4f}, Bias = {b[0]:.4f}")
```
