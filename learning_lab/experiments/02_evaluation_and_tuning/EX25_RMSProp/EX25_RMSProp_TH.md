# 🧠 EX25: การเพิ่มประสิทธิภาพด้วย RMSProp (RMSProp Optimization)

Root Mean Square Propagation (RMSProp) คือขั้นตอนวิธีในการเพิ่มประสิทธิภาพแบบปรับอัตราการเรียนรู้ได้ (Adaptive learning rate optimization algorithm) ซึ่งเสนอโดย Geoffrey Hinton ขั้นตอนนี้จะช่วยแก้ปัญหาอัตราการเรียนรู้ที่หายไป (Vanishing) หรือระเบิดขึ้น (Exploding) โดยการปรับขนาดการอัปเดตน้ำหนักตามค่าเฉลี่ยเคลื่อนที่ (Running average) ของกำลังสองของเกรเดียนต์ล่าสุด

---

## 1. ปัญหาของ AdaGrad (ทำไมจึงต้องมี RMSProp)
เพื่อทำความเข้าใจ RMSProp เราต้องย้อนไปดูอัลกอริทึมรุ่นก่อนหน้าอย่าง **AdaGrad** โดย AdaGrad จะปรับขนาดอัตราการเรียนรู้ของน้ำหนักแต่ละตัวโดยการหารด้วยผลรวมของกำลังสองของเกรเดียนต์ย้อนหลัง *ทั้งหมด*:

$$\mathbf{w}_{t+1} = \mathbf{w}_t - \frac{\alpha}{\sqrt{\sum_{\tau=1}^{t} g_\tau^2} + \epsilon} g_t$$

*   **ข้อบกพร่อง:** เนื่องจากกำลังสองของเกรเดียนต์ ($g_\tau^2$) จะมีค่าเป็นบวกเสมอ ผลรวมในตัวส่วนจึงเพิ่มขึ้นอย่างต่อเนื่องตลอดการฝึกสอน
*   **ผลลัพธ์:** ส่งผลให้อัตราการเรียนรู้ลดลงจนเหลือศูนย์ในที่สุด ทำให้การเรียนรู้หยุดชะงักก่อนที่โมเดลจะเข้าใกล้จุดต่ำสุดสัมบูรณ์ (Global minimum)

---

## 2. ทางออกด้วย RMSProp (The RMSProp Solution)
RMSProp แก้ปัญหานี้โดยการแทนที่ผลรวมสะสมด้วย **ค่าเฉลี่ยถ่วงน้ำหนักแบบลดลงอย่างทวีคูณ (Exponentially decaying average)** ของกำลังสองของเกรเดียนต์ ซึ่งหมายความว่าตัวปรับปรุงประสิทธิภาพ (Optimizer) จะ "ลืม" เกรเดียนต์ในอดีตที่ห่างไกลออกไป และจะปรับขนาดการอัปเดตตามขั้นตอนเกรเดียนต์ล่าสุดเท่านั้น

ในแต่ละขั้นตอน $t$:

### ขั้นตอนที่ 1: คำนวณค่าเฉลี่ยเคลื่อนที่ของกำลังสองของเกรเดียนต์ ($v_t$)
$$\mathbf{v}_t = \beta \mathbf{v}_{t-1} + (1 - \beta) g_t^2$$

โดยที่:
*   $g_t^2$ คือกำลังสองของเวกเตอร์เกรเดียนต์ปัจจุบันแบบทีละสมาชิก (Element-wise square)
*   $\beta$ คือพารามิเตอร์อัตราการลดลง (Decay rate parameter ซึ่งโดยทั่วไปจะตั้งค่าเป็น `0.9` หรือ `0.99`) ที่ควบคุมขอบเขตความทรงจำย้อนหลัง

### ขั้นตอนที่ 2: อัปเดตพารามิเตอร์ (Update Parameters)
$$\mathbf{w}_{t+1} = \mathbf{w}_t - \frac{\alpha}{\sqrt{\mathbf{v}_t} + \epsilon} \odot g_t$$

โดยที่:
*   $\alpha$ คืออัตราการเรียนรู้ (Learning Rate)
*   $\epsilon$ คือค่าคงที่ขนาดเล็กมาก ($10^{-8}$) เพื่อป้องกันไม่ให้เกิดการหารด้วยศูนย์
*   $\odot$ คือสัญลักษณ์การคูณแบบทีละสมาชิก (Element-wise multiplication)

### ผลลัพธ์ที่เกิดขึ้น (The Effect):
*   หากน้ำหนักใดมีค่าเกรเดียนต์ขนาดใหญ่ (แกว่งตัวอย่างรวดเร็ว) ค่า $v_t$ จะมีขนาดใหญ่ ซึ่งจะไป **หาร** อัตราการเรียนรู้และลดขนาดการอัปเดตลง ช่วยลดการแกว่งตัวได้
*   หากน้ำหนักใดมีค่าเกรเดียนต์ขนาดเล็ก (เคลื่อนที่ช้า) ค่า $v_t$ จะมีขนาดเล็ก ซึ่งจะช่วยเพิ่มอัตราการเรียนรู้และขยายขนาดการอัปเดตให้ใหญ่ขึ้น ช่วยเร่งการเรียนรู้ให้เร็วขึ้น

---

## 💻 การใช้งาน RMSProp Optimizer ใน PyTorch ด้วย Python

```python
import torch
import torch.nn as nn
import torch.optim as optim

model = nn.Sequential(nn.Linear(10, 2))

# Define RMSProp optimizer
# - lr: Learning rate (alpha)
# - alpha: Smoothing constant (equivalent to the decay factor beta, default 0.99)
# - eps: Epsilon (default 1e-8)
optimizer = optim.RMSprop(model.parameters(), lr=0.001, alpha=0.9, eps=1e-8)
```
