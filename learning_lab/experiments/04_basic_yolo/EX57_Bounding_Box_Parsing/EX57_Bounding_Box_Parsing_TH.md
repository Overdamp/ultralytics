# 🧠 EX57: การแจงส่วนกล่องขอบเขตวัตถุ (Bounding Box Parsing)

ในการใช้งานจริง การทำนายผล (Inference) ของโมเดลเป็นเพียงขั้นตอนแรกเท่านั้น หากต้องการนำผลลัพธ์ไปประยุกต์ใช้เพื่อตัดสินใจในขั้นต่อๆ ไป (เช่น การสั่งการระบบเตือนภัย การนับจำนวนวัตถุ หรือการตัดส่วนภาพเพื่อนำไปใช้งานเฉพาะจุด) คุณจำเป็นต้องรู้แนวทางการเข้าถึงข้อมูลโปรแกรมและแยกค่าพิกัด (coordinates), ป้ายกำกับคลาส (class labels) และค่าความมั่นใจ (confidence scores) ออกมาจากผลลัพธ์การทำนายของ YOLO

Ultralytics YOLO ช่วยอำนวยความสะดวกในเรื่องนี้โดยส่งค่ากลับมาในรูปของรายการ (list) ของวัตถุ `Results` บทเรียนนี้จะอธิบายวิธีการเข้าถึงและแจงส่วน (parsing) โครงสร้างข้อมูลเหล่านี้โดยใช้ Python API

---

## 1. โครงสร้างของ YOLO `Results`

เมื่อคุณรันคำสั่ง `results = model(source)` ตัว YOLO จะส่งคืนค่ากลับมาเป็นลิสต์ของอ็อบเจกต์ `Results` (หนึ่งอ็อบเจกต์ต่อหนึ่งภาพในแบทช์ แม้ว่าคุณจะส่งรูปภาพเข้าไปเพียงภาพเดียวก็ตาม)

```
results (ลิสต์ของอ็อบเจกต์ Results)
 └── results[0] (อ็อบเจกต์ Results ลำดับแรก)
      ├── .names (พจนานุกรม Dict ที่ใช้จับคู่ระหว่าง Class ID และชื่อสตริงของคลาส)
      └── .boxes (อ็อบเจกต์ Boxes ที่บรรจุข้อมูลกล่องขอบเขตที่ตรวจจับได้)
           ├── .cls  (เทนเซอร์: รหัสคลาส หรือ Class IDs)
           ├── .conf (เทนเซอร์: คะแนนความมั่นใจ หรือ Confidence scores)
           ├── .xyxy (เทนเซอร์: พิกัด [xmin, ymin, xmax, ymax] ในหน่วยพิกเซล)
           └── .xywh (เทนเซอร์: พิกัด [x_center, y_center, width, height] ในหน่วยพิกเซล)
```

แต่ละแอตทริบิวต์ภายใต้ `.boxes` จะถูกเก็บไว้ในรูปเทนเซอร์ของ PyTorch (PyTorch Tensor) เนื่องจากเทนเซอร์เหล่านี้อาจถูกคำนวณอยู่บนการ์ดจอ (GPU) คุณจึงต้องย้ายตำแหน่งข้อมูลและแปลงประเภทข้อมูล (type casting) อย่างถูกต้องเหมาะสม

---

## 2. คำอธิบายรูปแบบพิกัด (Coordinate Formats)

YOLO มีรูปแบบพิกัดกล่องขอบเขตวัตถุหลายรูปแบบ เพื่อรองรับเวิร์กโฟลว์คอมพิวเตอร์วิทัศน์ที่ต่างกัน:

1.  **`xyxy` (หน่วยพิกเซลดิบ):** $[x_{\min}, y_{\min}, x_{\max}, y_{\max}]$ มีประโยชน์สำหรับการวาดรูปกล่องสี่เหลี่ยมลงบนภาพโดยตรงด้วย OpenCV (`cv2.rectangle`) หรือการตัดรูปภาพเฉพาะจุด (cropping): `image[ymin:ymax, xmin:xmax]`
2.  **`xywh` (หน่วยพิกเซลดิบ):** $[x_{\text{center}}, y_{\text{center}}, \text{width}, \text{height}]$ เหมาะอย่างยิ่งสำหรับการหาจุดกึ่งกลางของวัตถุ (centroid) หรือใช้ประเมินระยะห่างเชิงพื้นที่
3.  **`xyxyn` / `xywhn` (พิกัดแบบปรับขนาดมาตรฐานแล้ว - Normalized Coordinates):** พิกัดเหล่านี้จะมีค่าถูกปรับทอนสเกลให้อยู่ในช่วง $0.0$ ถึง $1.0$ โดยอิงจากขนาดความกว้างและสูงของภาพต้นฉบับ เหมาะสำหรับนำไปเขียนลงในไฟล์ข้อความฉลากกำกับข้อมูล (YOLO label text files) หรือนำไปสเกลเข้ากับความละเอียดรูปภาพขนาดอื่น

## 3. ตัวอย่างการเขียนโค้ดด้วย Python (Python Code Demonstration)

สคริปต์ต่อไปนี้สาธิตวิธีการสกัดข้อมูลพารามิเตอร์ต่างๆ จากกล่องขอบเขตวัตถุอย่างละเอียด:

```python
import cv2
from ultralytics import YOLO

# 1. โหลดโมเดลที่เทรนไว้แล้วและเริ่มการทำนายผล
model = YOLO("yolo11n.pt")
results = model("demo.jpg")  # results จะเป็นรูปแบบ list

# 2. เข้าถึงผลลัพธ์ภาพแรก (เนื่องจากเราป้อนรูปภาพเข้าไปภาพเดียว)
first_result = results[0]

# แสดงตารางแมปชื่อคลาส (เช่น {0: 'person', 1: 'bicycle', ...})
class_names = first_result.names

# 3. สกัดกล่องวัตถุ (Boxes)
boxes = first_result.boxes

# หากไม่พบวัตถุเลย ให้แสดงข้อความแจ้งเตือนและสิ้นสุดการทำงาน
if len(boxes) == 0:
    print("ไม่พบวัตถุใดๆ ในรูปภาพ")
else:
    print(f"ตรวจพบวัตถุทั้งหมด {len(boxes)} รายการ")
    
    # 4. ลูปผ่านกล่องขอบเขตวัตถุแต่ละรายการ
    for i in range(len(boxes)):
        # การเข้าถึงแอตทริบิวต์ย่อย
        # เราใช้คำสั่ง .cpu() เพื่อย้ายเทนเซอร์มายัง RAM หลัก และ .item() เพื่อดึงค่าเดี่ยวออกมา
        cls_id = int(boxes.cls[i].cpu().item())
        conf = float(boxes.conf[i].cpu().item())
        
        # ดึงพิกัดในฟอร์แมตต่างๆ
        xyxy = boxes.xyxy[i].cpu().numpy()  # รูปแบบอาร์เรย์ [xmin, ymin, xmax, ymax]
        xywh = boxes.xywh[i].cpu().numpy()  # รูปแบบอาร์เรย์ [x_center, y_center, w, h]
        
        # แปลง Class ID ไปเป็นชื่อสตริงที่มนุษย์เข้าใจได้
        label = class_names[cls_id]
        
        print(f"\n--- รายการตรวจจับที่ #{i+1} ---")
        print(f"ประเภทวัตถุ (Class): {label} (ID: {cls_id})")
        print(f"ค่าความมั่นใจ (Confidence): {conf:.4f}")
        print(f"พิกัดกล่อง (xyxy): [{xyxy[0]:.1f}, {xyxy[1]:.1f}, {xyxy[2]:.1f}, {xyxy[3]:.1f}]")
        print(f"พิกัดกล่อง (xywh): จุดกึ่งกลาง=({xywh[0]:.1f}, {xywh[1]:.1f}), ขนาด={xywh[2]:.1f}x{xywh[3]:.1f}")
```

## 💡 คำแนะนำจากอาจารย์ (Professor Tips)

### 1. การทำงานแบบเวกเตอร์ (Vectorized Operations)
เพื่อหลีกเลี่ยงการทำลูปใน Python ทีละกล่องซึ่งอาจทำให้การทำงานช้าลงเมื่อภาพชิ้นนั้นๆ ตรวจพบวัตถุจำนวนมาก คุณสามารถแปลงเทนเซอร์ทั้งก้อนเป็นอาเรย์ NumPy หรือโอนถ่ายข้อมูลมายัง CPU ได้ในครั้งเดียว:
```python
# ดึงคลาสและค่าความเชื่อมั่นทั้งหมดรวดเดียว
all_classes = boxes.cls.cpu().numpy().astype(int)
all_confs = boxes.conf.cpu().numpy()
all_coords = boxes.xyxy.cpu().numpy()

for cls, conf, coord in zip(all_classes, all_confs, all_coords):
    print(f"พบวัตถุ {model.names[cls]} ด้วยค่าความมั่นใจ {conf:.2f} ที่พิกัด {coord}")
```
การประมวลผลเป็นกลุ่มในระดับ C ของ NumPy จะช่วยให้ระบบในโปรดักชันทำงานเร็วขึ้นอย่างมาก

### 2. ป้องกันข้อผิดพลาดในการโอนข้อมูลจาก GPU ไปยัง CPU (Safeguarding GPU to CPU Transitions)
หากคุณรัน YOLO บนการ์ดจอ (`cuda`) การพยายามเรียกคำสั่ง `.numpy()` โดยตรงบนเทนเซอร์จะส่งผลให้เกิดข้อผิดพลาดของ PyTorch:
`RuntimeError: Tensor on device cuda:0 is not convertable to numpy.`
คุณต้องเรียกคำสั่ง `.cpu()` ก่อนเรียกใช้ `.numpy()` เสมอเพื่อนำข้อมูลจากหน่วยความจำการ์ดจอ (VRAM) มายังหน่วยความจำระบบ (RAM) เสียก่อน

### 3. การตัดส่วนรูปภาพวัตถุเพื่อประมวลผลต่อ (Cropping Regions of Interest - ROI)
คุณสามารถดึงส่วนภาพวัตถุที่ตรวจพบออกมาจากภาพต้นฉบับด้วย OpenCV โดยอิงตามพิกัด `xyxy`:
```python
img = cv2.imread("demo.jpg")
for box in boxes:
    # แปลงพิกัดเป็นจำนวนเต็มเพื่อนำไปดึงค่าดัชนีภาพ
    x1, y1, x2, y2 = map(int, box.xyxy[0].cpu().numpy())
    roi = img[y1:y2, x1:x2]
    # ตอนนี้คุณสามารถบันทึกหรือส่งภาพย่อย (ROI) นี้ไปจำแนกต่อในโมเดลอื่นๆ ได้แล้ว!
```
