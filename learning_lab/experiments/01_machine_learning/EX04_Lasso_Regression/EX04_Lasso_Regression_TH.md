# 🧠 EX04: ทฤษฎีการถดถอยแบบลาสโซ (Lasso Regression Theory) (การคุมค่าแบบ L1 - L1 Regularization)

ในหัวข้อนี้ เราจะมาศึกษาร่วมกันเกี่ยวกับ **การถดถอยแบบลาสโซ (Lasso Regression)** (หรือ Least Absolute Shrinkage and Selection Operator) ซึ่งเป็นเทคนิคการควบคุมค่าสัมประสิทธิ์ (regularization) ที่เพิ่มค่าปรับแบบ L1 (L1 penalty) เข้าไปในฟังก์ชันการสูญเสีย ทำให้มีคุณสมบัติในการคัดเลือกคุณลักษณะ (feature selection) ในตัวเอง

---

## 1. แนวคิดหลัก (Core Concept)
แตกต่างจากการถดถอยแบบสัน ($L2$) ที่ช่วยลดขนาดน้ำหนักให้ใกล้ศูนย์แต่ยังคงรักษาคุณลักษณะทุกตัวไว้ การถดถอยแบบลาสโซ ($L1$) จะบีบน้ำหนักของคุณลักษณะที่มีความสำคัญน้อยกว่า **ให้เป็นศูนย์โดยสมบูรณ์ (exactly zero)** 

คุณสมบัตินี้ทำให้การถดถอยแบบลาสโซมีประโยชน์อย่างยิ่งในเรื่องต่อไปนี้:
1.  **การคัดเลือกคุณลักษณะ (Feature Selection):** ช่วยระบุและคงเหลือไว้เฉพาะคุณลักษณะที่มีความสามารถในการทำนายสูงสุดโดยอัตโนมัติ
2.  **ความเบาบางของแบบจำลอง (Model Sparsity):** ช่วยสร้างแบบจำลองที่เรียบง่ายขึ้น อธิบายผลลัพธ์ได้ง่ายขึ้นเนื่องจากมีสัมประสิทธิ์ที่ไม่เป็นศูนย์จำนวนน้อยลง

---

## 2. สูตรทางคณิตศาสตร์ (Mathematical Formulation)

### A. ฟังก์ชันการสูญเสียที่มีการลงโทษแบบ L1 (The Cost Function with L1 Penalty)
ลาสโซจะปรับเปลี่ยนฟังก์ชันการสูญเสียแบบความคลาดเคลื่อนกำลังสองเฉลี่ย (MSE) โดยการบวกผลรวมของค่าสัมบูรณ์ของน้ำหนัก คูณด้วยพารามิเตอร์ $\lambda$ เพิ่มเข้าไป:

$$J(w, b) = \frac{1}{2m} \sum_{i=1}^{m} \left( h_{w,b}(x^{(i)}) - y^{(i)} \right)^2 + \lambda \sum_{j=1}^{n} |w_j|$$

โดยที่:
*   $\lambda \ge 0$ คือความแรงของการคุมค่าสัมประสิทธิ์
*   $|w_j|$ คือค่าสัมบูรณ์ของค่าน้ำหนัก
*   เช่นเดียวกับแบบสัน พจน์ไบแอส $b$ จะ **ไม่** ถูกนำมาคิดบทลงโทษนี้

### B. เรขาคณิตของการคุมค่าแบบ L1 เทียบกับ L2 (Geometry of L1 vs. L2 Regularization)
เหตุใด L1 จึงขับเคลื่อนค่าน้ำหนักให้เป็นศูนย์ได้พอดี ในขณะที่ L2 ทำไม่ได้?
*   **ขอบเขตข้อจำกัดของ L2 (วงกลม):** พื้นที่ข้อจำกัดของการลงโทษแบบ L2 จะเป็นทรงกลม/วงกลม ($w_1^2 + w_2^2 \le t$) เส้นชั้นระดับ (contours) ของฟังก์ชันการสูญเสียมักจะสัมผัสกับวงกลมนี้ที่จุดซึ่งน้ำหนักมีขนาดเล็กแต่ไม่เป็นศูนย์
*   **ขอบเขตข้อจำกัดของ L1 (รูปข้าวหลามตัด):** พื้นที่ข้อจำกัดของการลงโทษแบบ L1 จะเป็นรูปข้าวหลามตัด ($|w_1| + |w_2| \le t$) ซึ่งมีมุมแหลมอยู่บนแกนพิกัด เส้นชั้นระดับของการสูญเสียมีโอกาสสูงมากที่จะไปชนตรงมุมแหลมเหล่านี้ก่อน ส่งผลให้น้ำหนักของคุณลักษณะตามแนวแกนนั้น ๆ มีค่าเท่ากับศูนย์พอดี

## 🔬 กรณีศึกษาทางวิสัยทัศน์คอมพิวเตอร์: การจำแนกประเภทกรอบล้อมรอบ (Bounding Box Classification)
สมมติว่าเราต้องการจำแนกประเภทวัตถุในชุดข้อมูล PTT ของคุณ (เช่น การแยกแยะระหว่าง `lever-valve` กับ `control-valve` ภายในชุดข้อมูล [overall-ptt-object-detection.v11i.yolov11](file:///home/luke/ai_training/ultralytics/datasets/coco8/overall-ptt-object-detection.v11i.yolov11)) โดยพิจารณาจากลักษณะเฉพาะของกรอบล้อมรอบ (bounding box):
1.  `x1`: ความกว้างของกรอบล้อมรอบ
2.  `x2`: ความสูงของกรอบล้อมรอบ
3.  `x3`: อัตราส่วนภาพ (ความกว้าง / ความสูง)
4.  `x4`: ค่าเฉลี่ยความเข้มข้นของพิกเซล (ความตัดกันของสี)
5.  `x5`: พิกัดจุดศูนย์กลางของภาพ (ตำแหน่งในรูปภาพ)

### การประยุกต์ใช้แบบจำลองลาสโซ:
หากตำแหน่งของวัตถุในเฟรมภาพ (`x5`) และความแตกต่างของพื้นหลัง (`x4`) ไม่มีส่วนเกี่ยวข้องกับการจำแนกประเภทวาล์ว การถดถอยแบบลาสโซจะขับเคลื่อนสัมประสิทธิ์ของตัวแปรเหล่านี้ให้เป็นศูนย์โดยสมบูรณ์:
*   $w_4 \to 0$
*   $w_5 \to 0$

ทำให้เราเหลือแบบจำลองที่มีความเบาบาง (sparse model) ซึ่งมีเฉพาะคำอธิบายด้านรูปร่างเท่านั้น:
$$\hat{y} = w_0 + w_1 \cdot \text{width} + w_2 \cdot \text{height} + w_3 \cdot \text{aspect\_ratio}$$
