# 🧠 EX05: ทฤษฎีการถดถอยโลจิสติก (Logistic Regression Theory)

ในหัวข้อนี้ เราจะมาศึกษาร่วมกันเกี่ยวกับ **การถดถอยโลจิสติก (Logistic Regression)** ซึ่งเป็นอัลกอริทึมพื้นฐานและตัวเปรียบเทียบมาตรฐาน (baseline) สำหรับงานจำแนกประเภทข้อมูลแบบสองกลุ่ม (binary classification)

---

## 1. แนวคิดหลัก (Core Concept)
แม้ว่าจะมีคำว่า "การถดถอย (regression)" อยู่ในชื่อ แต่อัลกอริทึมการถดถอยโลจิสติกนั้นแท้จริงแล้วใช้สำหรับงาน **การจำแนกประเภท (Classification)** โดยจะทำนายความน่าจะเป็นที่ข้อมูลนำเข้า $x$ จะอยู่ในกลุ่มหรือคลาสเริ่มต้น ($y=1$)

แทนที่จะใช้ผลลัพธ์ที่เป็นเส้นตรงแบบเดิม อัลกอริทึมนี้จะนำผลลัพธ์เชิงเส้นนั้นส่งผ่านไปยังฟังก์ชันบีบอัดค่าที่เรียกว่า **ฟังก์ชันซิกมอยด์ (Sigmoid Function หรือ Logistic Function)** เพื่อจำกัดค่าผลลัพธ์ให้อยู่ในช่วงระหว่าง $0$ ถึง $1$ เสมอ

---

## 2. สูตรทางคณิตศาสตร์ (Mathematical Formulation)

### A. ฟังก์ชันซิกมอยด์ (The Sigmoid Function)
ฟังก์ชันซิกมอยด์ $\sigma(z)$ จะทำหน้าที่แปลงจำนวนจริงใด ๆ ให้กลายเป็นค่าความน่าจะเป็นที่อยู่ระหว่าง 0 และ 1:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

### B. ฟังก์ชันสมมติฐาน (The Hypothesis Function)
เรากำหนดความสัมพันธ์เชิงเส้นของข้อมูลนำเข้าเป็น $z = \mathbf{w}^T \mathbf{x} + b$ และส่งผ่านค่านั้นเข้าไปในฟังก์ชันซิกมอยด์:

$$\hat{y} = h_{\mathbf{w}}(\mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}$$

โดยที่ $\hat{y} = P(y=1 | x)$ แทนค่าความน่าจะเป็นที่ข้อมูลตัวอย่างนั้น ๆ จะถูกจัดอยู่ในคลาส 1

### C. ฟังก์ชันการสูญเสีย: เอนโทรปีข้ามแบบสองกลุ่ม (Binary Cross-Entropy / Log Loss)
เราไม่สามารถใช้ความคลาดเคลื่อนกำลังสองเฉลี่ย (MSE) กับการถดถอยโลจิสติกได้ เนื่องจากฟังก์ชันซิกมอยด์จะทำให้ฟังก์ชันการสูญเสียไม่มีลักษณะนูน (non-convex) ซึ่งส่งผลให้มีจุดต่ำสุดเฉพาะที่ (local minima) หลายจุด เราจึงหันมาใช้ฟังก์ชันการสูญเสียแบบ **เอนโทรปีข้ามแบบสองกลุ่ม (Binary Cross-Entropy Loss)** หรือเรียกว่า Log Loss แทน:

$$J(w, b) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(\hat{y}^{(i)}) + (1 - y^{(i)}) \log(1 - \hat{y}^{(i)}) \right]$$

*   หากค่าจริง $y^{(i)} = 1$ พจน์ที่สองจะมีค่าเป็น 0 และจะลงโทษ (penalize) การทำนายที่มีค่าห่างจาก 1
*   หากค่าจริง $y^{(i)} = 0$ พจน์แรกจะมีค่าเป็น 0 และจะลงโทษการทำนายที่มีค่าห่างจาก 0

## 🔬 กรณีศึกษาทางวิสัยทัศน์คอมพิวเตอร์: การจำแนกประเภทเกจวัด (Gauge Classification)
สมมติว่า YOLO ตรวจจับชิ้นส่วนที่เป็นเกจวัดในชุดข้อมูล PTT ของคุณ ([overall-ptt-object-detection.v11i.yolov11](file:///home/luke/ai_training/ultralytics/datasets/coco8/overall-ptt-object-detection.v11i.yolov11)) และคุณต้องการจัดจำแนกว่ามันคือ `analog-gauge` (เกจแบบเข็มชี้: $y=1$) หรือ `digital-gauge` (เกจแบบตัวเลขดิจิทัล: $y=0$) โดยวิเคราะห์จาก:
1.  `x1`: อัตราส่วนภาพของกรอบล้อมรอบ (เกจวัดแบบเข็มชี้มักจะมีรูปทรงสี่เหลี่ยมจัตุรัส/วงกลม อัตราส่วนใกล้เคียง 1.0 ส่วนเกจวัดดิจิทัลมักเป็นรูปสี่เหลี่ยมผืนผ้า)
2.  `x2`: ความหนาแน่นของตัวอักษรข้อความ (ใช้เทคนิค OCR)

การถดถอยโลจิสติกจะคำนวณและส่งค่าความน่าจะเป็นออกมา:
$$P(\text{analog-gauge}) = \sigma(w_1 \cdot \text{aspect\_ratio} + w_2 \cdot \text{character\_density} + b)$$

หากค่าความน่าจะเป็นที่ได้มีค่า $\ge 0.5$ เราจะจำแนกชิ้นส่วนนั้นว่าเป็น `analog-gauge`
