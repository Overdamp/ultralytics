# 🧠 EX07: ทฤษฎีต้นไม้ตัดสินใจ (Decision Tree Theory)

ในหัวข้อนี้ เราจะมาศึกษาร่วมกันเกี่ยวกับ **ต้นไม้ตัดสินใจ (Decision Tree)** ซึ่งเป็นอัลกอริทึมแบบไม่เป็นเส้นตรง (non-linear) ที่มีความสามารถหลากหลาย โดยใช้ได้ทั้งงานจำแนกประเภท (classification) และงานถดถอย (regression)

---

## 1. แนวคิดหลัก (Core Concept)
ต้นไม้ตัดสินใจทำงานคล้ายกับผังงาน (flowchart) โดยจะเริ่มต้นที่โหนดราก (root node) จากนั้นจะแบ่งชุดข้อมูลออกเป็นชุดย่อย ๆ ตามค่าของคุณลักษณะต่าง ๆ เพื่อทำให้กิ่งก้านที่ได้มีความบริสุทธิ์ (purity) ของคลาสข้อมูลสูงที่สุด การแบ่งย่อยเช่นนี้จะทำซ้ำไปเรื่อย ๆ แบบเรียกซ้ำ (recursive splitting) จนกระทั่งบรรลุเงื่อนไขการหยุดที่กำหนดไว้ (เช่น ความลึกสูงสุดของต้นไม้) ณ โหนดใบ (leaf nodes)

---

## 2. สูตรทางคณิตศาสตร์ (Mathematical Formulation)

เพื่อพิจารณาเกณฑ์การเลือกคุณลักษณะที่ดีที่สุดในการแบ่งข้อมูล เราจะวัด "ความไม่บริสุทธิ์" (impurity) หรือความไม่เป็นระเบียบของป้ายกำกับคลาส (labels) ในโหนดนั้น ๆ

### A. เอนโทรปี (Entropy) (ความไม่เป็นระเบียบ)
เอนโทรปีทำหน้าที่วัดความไม่บริสุทธิ์ของชุดข้อมูล $S$ โดยคำนวณจากสูตร:

$$H(S) = -\sum_{i=1}^{c} p_i \log_2 p_i$$

โดยที่:
*   $c$ คือจำนวนคลาสข้อมูลทั้งหมด
*   $p_i$ คือความน่าจะเป็นหรือสัดส่วนของข้อมูลตัวอย่างที่อยู่ในคลาส $i$
*   หากโหนดมีความบริสุทธิ์อย่างสมบูรณ์ (เช่น มีเฉพาะคลาส 0 ทั้งหมด) ค่า $H(S) = 0$ แต่หากมีข้อมูลแบ่งครึ่งอย่างละ 50/50 ค่า $H(S) = 1$

### B. อัตราการได้รับข้อมูล (Information Gain)
เราจะเลือกการแบ่งข้อมูลที่ช่วยลดค่าเอนโทรปีได้มากที่สุด ค่าการลดลงนี้เรียกว่า **อัตราการได้รับข้อมูล (Information Gain: IG)**:

$$IG(S, A) = H(S) - \sum_{v \in \text{values}(A)} \frac{|S_v|}{|S|} H(S_v)$$

โดยที่ $A$ คือคุณลักษณะที่เลือกใช้ และ $S_v$ คือชุดข้อมูลย่อย of $S$ ที่มีค่าคุณลักษณะ $A$ เป็นค่า $v$

### C. ดัชนีความไม่บริสุทธิ์ของจีนี (Gini Impurity) (ทางเลือกอื่น)
มักเป็นที่นิยมใช้มากกว่าเอนโทรปีเนื่องจากไม่จำเป็นต้องคำนวณค่าลอการิทึม (ซึ่งช่วยให้การฝึกฝนแบบจำลองทำได้รวดเร็วยิ่งขึ้น):

$$\text{Gini}(S) = 1 - \sum_{i=1}^{c} p_i^2$$

## 🔬 กรณีศึกษาทางวิสัยทัศน์คอมพิวเตอร์: การส่งต่องานจากกรอบล้อมรอบ (Bounding Box Routing)
สมมติว่าคุณได้ฝึกฝนแบบจำลอง YOLO บนชุดข้อมูล [overall-ptt-object-detection.v11i.yolov11](file:///home/luke/ai_training/ultralytics/datasets/coco8/overall-ptt-object-detection.v11i.yolov11) และต้องการเขียนสคริปต์คัดแยกประเภทอย่างง่ายเพื่อคัดแยกวัตถุบนสายพานลำเลียง:

```
                  [ Root Node: Area > 15000px? ]
                             /         \
                           Yes          No
                           /              \
        [ Split 2: Aspect Ratio > 1.2? ]   [ Leaf: Small Fitting ]
                  /            \
                Yes             No
                /                 \
       [ Leaf: Control Valve ]  [ Leaf: Flange ]
```

ต้นไม้ตัดสินใจจะนำขนาดของกรอบล้อมรอบที่ได้จาก YOLO (`area`, `aspect_ratio`) มาวิเคราะห์และส่งต่อวัตถุเหล่านั้นไปยังหมวดหมู่ที่ถูกต้องโดยอัตโนมัติ
