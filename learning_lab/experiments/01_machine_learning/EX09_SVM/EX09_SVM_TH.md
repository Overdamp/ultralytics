# 🧠 EX09: ทฤษฎีซัพพอร์ตเวกเตอร์แมชชีน (Support Vector Machines - SVM Theory)

ในหัวข้อนี้ เราจะมาศึกษาร่วมกันเกี่ยวกับ **ซัพพอร์ตเวกเตอร์แมชชีน (Support Vector Machines: SVM)** ซึ่งเป็นวิธีการจำแนกประเภทข้อมูลที่มีความทนทานสูง โดยทำหน้าที่ค้นหาไฮเปอร์เพลนการแบ่งส่วนที่เหมาะสมที่สุด (optimal separating hyperplane) ในปริภูมิคุณลักษณะที่มีหลายมิติ (high-dimensional feature spaces)

---

## 1. แนวคิดหลัก (Core Concept)
เป้าหมายของ SVM คือการค้นหาขอบเขตการตัดสินใจ (ไฮเปอร์เพลน หรือ hyperplane) ที่จะคอยแบ่งข้อมูลออกเป็นสองกลุ่ม โดยในขณะเดียวกันก็จะขยาย **ระยะขอบ (margin)** (ซึ่งคือระยะห่างระหว่างขอบเขตการตัดสินใจกับจุดข้อมูลที่อยู่ใกล้ที่สุดของทั้งสองกลุ่ม เรียกว่า **ซัพพอร์ตเวกเตอร์** หรือ **support vectors**) ให้กว้างที่สุดเท่าที่จะทำได้

หากข้อมูลไม่สามารถแบ่งแยกด้วยเส้นตรงได้ในปริภูมิเดิม (not linearly separable) SVM จะใช้วิธีจับคู่และแปลงคุณลักษณะเหล่านั้นไปยังปริภูมิที่มีมิติสูงขึ้นเพื่อทำให้ข้อมูลสามารถแบ่งแยกคลาสออกจากกันได้ โดยขั้นตอนนี้สามารถทำได้อย่างมีประสิทธิภาพผ่าน **ทริกเคอร์เนล (Kernel Trick)**

---

## 2. สูตรทางคณิตศาสตร์ (Mathematical Formulation)

### A. ปัญหาการปรับค่าให้เหมาะสมที่สุด (Hard Margin)
กำหนดให้ไฮเปอร์เพลนเขียนอยู่ในรูปของ $\mathbf{w}^T \mathbf{x} + b = 0$ สำหรับชุดข้อมูลฝึกฝนที่สามารถแบ่งแยกด้วยเส้นตรงได้โดยสมบูรณ์:

$$y^{(i)} (\mathbf{w}^T \mathbf{x}^{(i)} + b) \ge 1 \quad \forall i$$

เพื่อขยายระยะขอบ (ซึ่งมีค่าเท่ากับ $\frac{2}{\|\mathbf{w}\|}$) ให้กว้างที่สุด เราจะดำเนินการย่อขนาดของค่าน้ำหนัก (weights) ให้เล็กที่สุด:

$$\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2 \quad \text{ภายใต้เงื่อนไข } y^{(i)}(\mathbf{w}^T \mathbf{x}^{(i)} + b) \ge 1$$

### B. Soft Margin (การจัดการกับสัญญาณรบกวน)
หากกลุ่มข้อมูลมีส่วนที่ซ้อนทับกัน เราจะเพิ่มตัวแปรปรับหย่อน (slack variables) $\xi_i$ เพื่อยินยอมให้เกิดการล่วงล้ำระยะขอบได้เล็กน้อย:

$$\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2 + C \sum_{i=1}^{m} \xi_i$$

โดยที่ $C$ คือไฮเปอร์พารามิเตอร์ควบคุมการคุมค่า (regularization hyperparameter):
*   หากกำหนดค่า $C$ สูง จะเป็นการลงโทษความผิดพลาดในการจำแนกประเภทอย่างรุนแรง ส่งผลให้ได้ระยะขอบที่แคบลง (ความแปรปรวนสูง ความเบี่ยงเบนต่ำ)
*   หากกำหนดค่า $C$ ต่ำ จะยอมให้เกิดความผิดพลาดในการจำแนกประเภทได้มากขึ้น ส่งผลให้ได้ระยะขอบที่กว้างขึ้น (ความแปรปรวนต่ำ ความเบี่ยงเบนสูง)

### C. ทริกเคอร์เนล (Kernel Trick) (ขอบเขตแบบไม่เป็นเส้นตรง)
แทนที่เราจะต้องคำนวณการแปลงเวกเตอร์คุณลักษณะไปยังมิติที่สูงขึ้นด้วยตนเอง เราจะใช้ฟังก์ชันเคอร์เนล $K(\mathbf{x}, \mathbf{z})$ ที่ทำหน้าที่คำนวณผลคูณภายใน (dot product) ในปริภูมิที่มีมิติสูงขึ้นโดยตรง:
*   **เคอร์เนลฟังก์ชันฐานเชิงรัศมี (Radial Basis Function (RBF) Kernel):**
    $$K(\mathbf{x}, \mathbf{z}) = \exp(-\gamma \|\mathbf{x} - \mathbf{z}\|^2)$$

## 🔬 กรณีศึกษาทางวิสัยทัศน์คอมพิวเตอร์: แกนวาล์ว เทียบกับ ก้านสูบขัดมัน (Valve-Stem vs. Polished-Rod)
สมมติว่าคุณต้องการจำแนกคุณลักษณะทางภาพสองประเภทที่มีโครงสร้างคล้ายคลึงกันอย่างมาก ได้แก่ `polished-rod` (ก้านสูบขัดมัน) และ `manual-valve-stem` (แกนวาล์วปรับด้วยมือ) จากชุดข้อมูล [overall-ptt-object-detection.v11i.yolov11](file:///home/luke/ai_training/ultralytics/datasets/coco8/overall-ptt-object-detection.v11i.yolov11)

เนื่องจากทั้งสองสิ่งนี้ต่างก็เป็นก้านโลหะรูปทรงกระบอกเหมือนกัน คุณลักษณะเชิงเส้นธรรมดาอาจมีข้อมูลที่ทับซ้อนกันอยู่ แบบจำลอง SVM ที่ใช้ **RBF Kernel** จะนำฮิสโตแกรมของขอบ (edge histograms) ที่มีมิติสูง หรือคุณลักษณะที่ได้จากโครงข่ายประสาทเทียมแบบคอนโวลูชัน (CNN features) ของกรอบล้อมรอบ มาใช้สร้างขอบเขตการตัดสินใจแบบไม่เป็นเส้นตรง เพื่อจำแนกประเภทพวกมันออกจากกันด้วยความมั่นใจสูง
